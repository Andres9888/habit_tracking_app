# ChainDay App Preview Video Script

## Video Specifications
- **Duration:** 30 seconds
- **Resolution:** 1920x1080 (Full HD)
- **Format:** MP4 (H.264 codec)
- **Audio:** Upbeat, motivating background music (royalty-free)
- **Voiceover:** Optional, friendly female voice

## Scene Breakdown

### Scene 1: Opening - Hook (0:00 - 0:03)
- **Visual:** White screen with app icon (🔗 chain link) appearing
- **Animation:** Icon bounces in, then splits into 3 colored dots
- **Text Overlay:** "Build Habits That Stick"
- **Duration:** 3 seconds
- **Transition:** Fade to next scene

### Scene 2: Onboarding - First Launch (0:03 - 0:08)
- **Visual:** iPhone 15 Pro frame showing onboarding flow
  - Welcome screen with "ChainDay" logo
  - Quick tap "Get Started"
  - Simple name input: "Morning Run"
  - Icon picker: selects 🏃
- **Text Overlay:** "Simple Setup. Fast Results."
- **Duration:** 5 seconds
- **Transition:** Slide right

### Scene 3: Create Habit - Quick Start (0:08 - 0:13)
- **Visual:** Create habit modal
  - User types "Morning Run"
  - Selects 🏃 icon
  - Picks green color
  - Taps "Create Habit"
  - Habit appears in list with animation
- **Text Overlay:** "Add Habits in Seconds"
- **Duration:** 5 seconds
- **Transition:** Slide up

### Scene 4: Main View - Habit List (0:13 - 0:18)
- **Visual:** Scrolling habit list showing:
  - Morning Run with 7-day streak (all green dots)
  - Meditation with 4-day streak
  - Reading with 3-day streak
  - Drink Water with 9-day streak
  - User taps Morning Run checkbox → confetti animation
- **Text Overlay:** "Watch Your Streaks Grow"
- **Duration:** 5 seconds
- **Transition:** Zoom in on habit

### Scene 5: Mark Complete - Celebration (0:18 - 0:23)
- **Visual:** Close up of completing a habit
  - Finger taps checkbox on "Morning Run"
  - Checkmark animation
  - Streak counter increments from 7 to 8
  - Small confetti burst
  - "8 day streak 🔥" appears
- **Text Overlay:** "Celebrate Every Win"
- **Duration:** 5 seconds
- **Transition:** Fade

### Scene 6: Features Montage (0:23 - 0:27)
- **Visual:** Quick cuts showing:
  - Habit Strength screen (87% bar)
  - Calendar view with green completed days
  - Achievements screen with medals
  - XP progress bar filling
- **Text Overlay:** "Track Strength. Unlock Achievements."
- **Duration:** 4 seconds
- **Transition:** Fast cuts

### Scene 7: Closing - Call to Action (0:27 - 0:30)
- **Visual:**
  - App Store "GET" button appears
  - App icon and rating: ⭐⭐⭐⭐⭐ (4.8)
  - Tagline: "Don't break the chain"
- **Text Overlay:** "Download ChainDay Today"
- **Duration:** 3 seconds
- **Fade to black**

## Visual Style Guidelines

### Colors
- **Primary:** #059669 (Emerald green)
- **Secondary:** #667eea (Purple)
- **Accent:** #f5576c (Pink)
- **Background:** White/off-white for app screens, black for celebration scenes

### Typography
- **Headlines:** SF Pro Display Bold / Roboto Bold
- **Body:** SF Pro Text / Roboto Regular
- **Size:** Headlines 48-60px, Body 18-24px

### Animations
- **Timing:** 280ms spring animations
- **Easing:** springify().damping(18)
- **Style:** Smooth, natural movements, slight bounce on interactions

### Device Frame
- **Model:** iPhone 15 Pro
- **Color:** Natural Titanium
- **Orientation:** Portrait
- **Notch:** Dynamic Island visible

## Production Notes

### Tools Suggested
- **Screen Recording:** QuickTime Player (Mac) or OBS
- **Editing:** Final Cut Pro, Premiere Pro, or DaVinci Resolve
- **Animation:** After Effects for polished effects
- **Icons:** SF Symbols or Feather Icons
- **Fonts:** SF Pro (iOS native) or Roboto

### File Export Settings
- **Format:** MP4
- **Codec:** H.264
- **Bitrate:** 15-20 Mbps
- **Audio:** AAC 192kbps
- **Frame Rate:** 30 fps
- **Color Space:** sRGB

### Subtitle/Caption Style
- **Font:** Helvetica Neue Bold, white text
- **Background:** Semi-transparent black (80% opacity)
- **Position:** Bottom center
- **Size:** 24px for main text, 18px for captions

## Key Messaging Points
1. **Simplicity:** "Setup in seconds"
2. **Visual Progress:** "Watch streaks grow"
3. **Motivation:** "Celebrate wins"
4. **Features:** "Strength tracking, achievements"

## Success Metrics
- **Completion Rate:** Aim for 80%+ viewers watching entire video
- **Engagement:** Confetti moments should draw attention
- **Clear Value:** Features should be immediately understood
- **CTA:** End with clear download button
