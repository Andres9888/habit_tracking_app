## Context

Andres wants to understand what frontend improvements would move Chain Day from its current state to a $3,000 MRR app. The app currently has: $6.99/mo + $44.99/yr pricing via RevenueCat, 3-habit free limit, 7-day free trial, 3 premium packs (Huberman, Morning Mastery, Mindful Peak), share cards for virality. Recently removed 26k lines of dead premium features (affirmations, letters, vision board) to focus on core habit tracking.

The math: $3,000 MRR at ~$5/mo blended ARPU = 600 paying subscribers. At 3-5% conversion of MAU = need 12,000-20,000 MAU. Frontend improvements must increase one of: conversion rate, retention, ARPU, or viral coefficient.

### Risks
- Improving UI polish without improving conversion funnel metrics
- Adding features that increase complexity without increasing perceived premium value
- Optimizing for screenshots/design awards instead of revenue-driving behaviors
