## Context the executor must reuse (already researched — do not re-derive)
- **App = "Chain Day"**, React Native + Expo. Design language: warm-minimalist — parchment bg `#F5F1ED`, forest-green primary `#059669`/`#34D399`, burnished-gold reserved for streaks (<10% area). Fonts: Literata (serif H1/editorial), DM Sans (body/UI), JetBrains Mono (numeric), OpenDyslexic (a11y toggle). Icons: `lucide-react-native`. Motion: `react-native-reanimated` v4, `FadeInDown(280)`, `springs.standard {damping:18,stiffness:150}`.
- **Settings shell**: `src/components/SettingsModal/SettingsModal.tsx` renders the bespoke `Modal` in `fullScreen` variant (no gesture/backdrop close). In-modal mini-navigator with views `settings|archived|account|calendar` (`SettingsModal.hooks.ts`). Skeleton gates load. Search plumbing present but **not rendered** (`SettingsContent.tsx:15`, `query=''`). Accordion capability present but **unused** (all sections static).
- **Current IA** (`SettingsPrimarySections.tsx` → `SettingsSecondarySections.tsx`): Profile hero (with stats) → Pro/upgrade card → "Look & Feel" (Calendar look sub-page, Theme, Default growth icons, Compact cards) → "Reminders" (streak toggle + time) → "Habits" (Sort order, Completion sound, Archived habits, Export) → "Support" (Rate/Share/Feedback/What's New) → About footer (Privacy/Terms/version). Account sub-page: profile card (+duplicate stats), premium status, edit profile/email/restore, danger zone (sign out/delete).
- **Non-settings content (the constraint target)**: `ProfileHeroCard.tsx:57-68` → `useProfileStats()` renders `WeeklyCompletionRing.tsx` + `ProfileStatsRow.tsx:29-57` (Active Habits / Flawless Days / Lifetime Completions) + streak line (`ProfileHeroIdentity.tsx:52-65`). Real analytics computed in `profileStats.helpers.ts:32-89` off Convex `api.habits.*`. Duplicated on Account page (`ProfileCard.tsx:98`). `SettingsCountBadge.tsx` live count on "Archived habits" row (`HabitDataRows.tsx:23`). Trial/price metadata in `ProSettingsCard.tsx:12-18`, `TrialCard.tsx`.
- **Reusable primitives** (redesign should reuse, not reinvent): `ui/AnimatedPressable.tsx`, `Button/`, `Modal/` (fullScreen/bottomSheet), `ScreenHeader/` or bespoke `SettingsHeader.tsx` (editorial kicker + serif title), `SettingsSection.tsx`, `SettingsRow/` (row types: `toggle|navigation|selection|info` + badge/accessory). Tokens: `settingsColors.ts` (green tint = state row, warm-stone = nav row, red = destructive), `airyScale.ts` (`tileSize`, `tileRadius`, `rowPaddingV`).
- **Prior art / decisions to honor**: `docs/SPEC_settings-improvements-v2.md` (Phase 4 blocked on user confirm) — its architecture facts, gotchas, scope/out-of-scope. Gotchas: **single-tier monetization** (no Pro/freemium gating — do NOT add crowns/"unlock" copy), `CalendarPreview` "lying preview" bug (78% vs 92% hardcode), accordion motion must use `useExpandAnimation`/`springs.gentle`, `PremiumStatus` intentionally a distinct gradient CTA (don't wrap in `SettingsSection`). Dark-mode toggle was deliberately removed once (`docs/specs/settings/disable-dark-mode-temporarily.md`) — check before re-adding theme controls. Orphaned/dead: `sections/DataPrivacySection.tsx` (exported, never rendered), `AccountRow→HighContrastAccountRow→AccountRowContent` chain.
- **Prior mocks that ADDED stats (must be explicitly overridden)**: `.superdesign/design_iterations/settings_improvements_plan_1.html`, `settings_bestof_1.html`, `settings_port_before_after_1.html`; OD project `6e2f2a18` file `chainday-settings-improved-2.html`. Full `.superdesign` settings iteration list is the spec author's precedent library. OD "Settings Page Fable" project (`892e01b2...`) is empty/awaiting_input — the greenfield target for the downstream OD run.
