Change summary

P1

Expose hidden settings

Add Accessibility and Display sections for prefs already in Convex hooks but not rendered in SettingsContent.

P1

Wire loading skeleton

Pass isLoading={settings === undefined} so SettingsModalSkeleton shows during Convex fetch.

P1

Mutation error feedback

Revert optimistic toggles on failure and show a toast or alert — no more silent desync.

P2

Manage subscription

Premium users get a direct link to App Store subscription management on the Account page.

P2

Permission banner

When notifications are denied, show an inline banner with "Open Settings" — same pattern as create-habit flow.

P2

Clearer labels & naming

Rename "Habit Management" → "Data", improve toggle copy, group sounds under Behavior.

P3

Dark mode picker

Theme selector (System / Light / Dark) once ThemeContext fully supports it end-to-end.

P3

Decompose SettingsContent

Split 381-line file into section components to meet the 100-line decomposition standard.
