UX AUDIT HABIT LIBRARY

"I don't know what habit to add"

The Habit Library has 318 templates, rich categories, and smart features — but the core user problem is discovery friction. Users who don't know what they want face choice paralysis, too many taps, and no personalization. Here are the pain points and proposed fixes.

1

Four surfaces fighting for attention

Featured hero, Trending carousel, Category grid, and Premium Packs all compete above the fold. The user came here to pick ONE habit — instead they face a decision about which browsing mode to use.

4

Search bar assumes the user knows what they want

The search bar is the first interactive element below the header. But the core user problem is "I don't know what habit to add." You can't search for something you can't name. Search should be available but not the primary discovery mechanism.

Summary of Changes

REMOVE / REPLACE
  • Featured hero card (time-based)
  • Search bar as primary element
  • "Science-backed" subtitle claim
  • Metadata pill badges on browse cards
  • Fullsize preview as required step
ADD / ENHANCE
  • Intent chips ("What do you want to improve?")
  • Quick Start with one-tap Add buttons
  • Gap analysis hero (personalized)
  • Inline Add on category drill cards
  • Category badges ("3 added", "Try this!")
  • Dynamic subtitle with user context
  • Trending excludes imported habits
IMPLEMENTATION PRIORITY
P0 Inline Add buttons on category drill cards — Lowest effort, highest friction reduction
P1 Intent chips + Quick Start section — Replaces search/featured, guides undecided users
P2 Personalization (gap analysis, dynamic subtitle, filtered trending) — Requires backend query changes
