Issues & Fixes

1
Hard-coded hex colors — Avatar (#7c3aed), Sign Out (#ef4444), Delete (#ef4444), divider (#e7e5e4) bypass theme system. Won't adapt in dark mode. Fix: use themeColors.status.premium, themeColors.status.error, themeColors.border
2
Shadow too heavy — Section cards use FAB-level elevation (height:4, radius:16, opacity:0.08). Fix: use shadows.card token (height:2, radius:8, opacity:0.06) — visible as subtler, more appropriate depth
3
Inconsistent divider — Account uses custom 0.5px inset divider while SettingsRow uses full-width border-b. Fix: adopt SettingsRow's border-b + borderColor: themeColors.border pattern
4
Missing subtitle — "Pin calendar header" is the only toggle without explanatory text. Fix: add subtitle='Keep the month header visible when scrolling'
5
Hardcoded version — Shows "1.0.0 (1)" as string literals. Fix: read from expo-constants for actual app version and build number
