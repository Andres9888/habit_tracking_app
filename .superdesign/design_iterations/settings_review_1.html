What changed

1

Export toast lies

HabitDataRows.tsx:25 fires “Export started…” on tap — before the format Alert even opens, and it stays on screen if you hit Cancel. Three feedback systems in one flow: toast, then Alert, then another Alert.

One in-app sheet, honest copy

Native Alert chain → a themed sheet matching the rest of Settings. Toast moves after the choice and names the format. Cancel leaves no trace.

2

Four orphaned settings

types.ts accepts celebrationsEnabled, showHabitStrengthPercentage, showCharacterScreen, onOpenHapticTest. Values persist in Convex; no row renders them.

Restore or delete — decide

Mock shows them restored into Look & Feel. If the handoff removal was intentional, strip the props and the Convex fields instead of leaving dead plumbing.

3

Sort order has no disclosure affordance

Right-chevron implies navigation, but tap expands inline. Chevron never rotates. Section sits low — picker can open below the fold with no scroll-into-view.

Rotating chevron + tinted open state

Chevron rotates 90°, pill goes green, row tints. Scroll-into-view on expand. Now visually distinct from Calendar look (sub-page) and Theme (inline segments).

4

Screen reader value gap

SettingsRow.tsx:71 exposes only accessibilityLabel={label}. VoiceOver reads “Sort order, button” — no current value, no expanded state.

accessibilityValue + accessibilityState

“Sort order, Newest first, expanded, button.” Same fix covers every selection row and both toggles.

5

Footer targets under 44px

12px caption + hitSlop={12} ≈ 36px tall. Below the HIG minimum.

hitSlop 16

Pushes Privacy / Terms past 44px without changing the quiet visual weight of the line.

6

Scroll hairline snaps

SettingsContent.tsx:36 flips opacity 0→1 the instant scrollY passes 4px. Reads as a flicker on light scrolls.

Interpolate over ~12px

Fades in with the scroll instead of popping.

7

Premium card pops in

ProSettingsCard.tsx:19 returns null while subscription state loads, then a full card appears — everything below jumps.

Reserve height, fade in

Placeholder holds the space; card fades once usePremium resolves. No reflow.

8

Stagger index gap

Primary sections animate 0–3, secondary hardcodes 5–7. Index 4 is skipped — and when the premium card is null (premium users) Support and footer still wait out the later delays.

Compute indexes from rendered children

Tail arrives on time whether or not the premium card renders.

9

Dead plumbing

onDeleteAccount / isDeletingAccount threaded through three components and rendered by none — the Account sub-page owns its own via useAccountActions. The search provider also wraps everything with query='' while every row runs rowMatchesQuery per render.

Cut the props, gate the filter

Not visible in the mock. Drop the delete props; short-circuit rowMatchesQuery when the query is empty so rows stop paying for a feature with no entry point.

10

Version isn’t copyable

Build number is kept for support triage, but neither the footer nor the Account page marks the text selectable.

Tap to copy

selectable + tap-to-copy with a confirmation toast. Support gets the exact build in one message.
