My pick

R1 (compact rounded-full "Edit ›" pill). Drops "Tap to" since the whole row already tells the user that. Adopts the app's existing rounded-full + 11px semibold convention used by PreviewChip and TierPickerTile, so it'll feel native to the rest of the screen. Roughly 33% narrower than current — frees up enough room for the description text to land cleanly. Stays visible at rest (which R3 sacrifices) and keeps the word "Edit" (which R2 sacrifices).

Audit also flagged: the dominant press feedback across the app is a scale-animation spring (HeaderButton, TierPickerTile use ~0.96 scale). I can bundle that with R1 in the implementation so the row press feels kinetic instead of just background-color-shifty.
