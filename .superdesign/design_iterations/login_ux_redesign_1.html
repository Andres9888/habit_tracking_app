1
SocialProofBadge exists but not rendered
src/screens/auth/components/SocialProofBadge/SocialProofBadge.tsx is fully implemented with fade-in animation but WelcomeScreen never imports it. Free trust signal left on the table.
Fix: Add <SocialProofBadge /> to WelcomeScreen heroSection
2
LegalFooter exists but not rendered
src/screens/auth/components/LegalFooter/LegalFooter.tsx links to Terms & Privacy but WelcomeScreen doesn't show it. App Store compliance risk.
Fix: Add <LegalFooter /> at bottom of WelcomeScreen
3
Logo inconsistency across screens
WelcomeScreen uses <Link> lucide icon on stone bg. SignInScreen uses 🔗 emoji on gradient bg. Two different visual identities on adjacent screens.
Fix: Create shared AnimatedLogo with gradient + SVG link icon
4
WelcomeScreen uses hardcoded colors
WelcomeScreen.styles.ts hardcodes #FAF8F5, #1c1917, #57534e while SignIn uses useThemeColors(). Will break when dark mode ships.
Fix: Migrate WelcomeScreen styles to useThemeColors()
5
SignIn form has no card container
SignUpScreen wraps its form in a card with shadow and padding. SignInScreen renders form fields flat. Users see different visual hierarchy for the same type of content.
Fix: Wrap SignIn form section in matching card component
6
Generic tagline lacks value proposition
"Build habits that stick" is functional but doesn't differentiate from competitors. A warmer alternative like "Build habits that last" or "Your daily momentum starts here" creates emotional connection.
Fix: Update tagline copy in WelcomeScreen
