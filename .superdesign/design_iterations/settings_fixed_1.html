What changed — callouts map to design review findings

  1. 1
    Unified UserIdentityCard — same component at Settings top (compact) and Account page (hero), shared tokens. Before: 40×40 avatar · py-3.5 · fontSize: 16 override · gap: 14. After: 48×48 avatar · py-4 · typography.body semibold · gap: spacing.md. Finding 1 in the review. Effort: Small.
  2. 2
    Section header legibility — tiny uppercase overline → semibold 15px title-case. Scanning the page by section becomes easier. Finding 6. Effort: Trivial.
  3. 3
    Toggle baseline locked — every right-side accessory sits on the same vertical center, regardless of whether the row has a subtitle. Cause: items-start on rows with subtitles. Fix: always items-center; top-align the icon chip instead if needed. Finding 2. Effort: Trivial (one line).
  4. 4
    Default growth icons → navigation row + sub-page — the inline "Customize" half-screen expansion is gone. The row now behaves like every other nav row in the app (icon + label + subtitle with preset + chevron). Tapping opens a dedicated sub-page (mirroring SortPicker). Finding 3. Effort: Medium (new sub-page, removes inline expansion logic).
Not shown in this single-screen mock but also in the review: reduce-motion support (Finding 4), tokenizing rgba overlays and gap values (Finding 5), 44×44 compliance on inline pickers (Finding 7), skeleton parity (Finding 9), HC token consolidation (Finding 10), Sign Out placement (Finding 14), Streak Reminders description layout (Finding 15).
