Why this differs from the benefit-driven mock
  • One metaphor, not four. Every new screen is a piece of the route system. Reader builds a single mental model instead of collecting four unrelated promises.
  • Mechanic-led, not promise-led. "You won't quit on day 42" is a promise. "Miss a day? Detour. Day 31. Strength 78." is the actual thing — you can see what happens.
  • Ends in action, not a Continue. Screen 7 is a real start — pick the easiest route, walk it. The hook ends with the user already on the map, not still being sold.
  • Name capture moves later. Personalization waits until after the user is moving. Asking for a name during the sell feels like data gathering; asking after they've started a route feels like onboarding the user, not the metric.
