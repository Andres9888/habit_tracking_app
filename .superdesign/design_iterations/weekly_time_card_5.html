Pace pill states

Computed from current total vs goal × (days elapsed / 7). Three states:

▲ on pace total ≥ proportional goal
▼ behind total < proportional goal by > 10%
★ goal hit total ≥ goal (week complete)

What we add

Stat Formula Shows when
Avg / day total ÷ days_elapsed weekly goal set
On pace pill total vs (goal × days_elapsed/7) weekly goal set
Time to go max(0, goal − total) weekly goal set
Daily streak consecutive trailing days where minutes ≥ daily_goal daily goal set
Hit rate days where minutes ≥ daily_goal / 7 daily goal set (already shown)
All stats computed client-side from the existing byDate Convex response — no schema changes, no new queries. ~30 lines of code, mostly in WeeklyTimeCard.tsx + a tiny computeProgressStats.ts helper.
