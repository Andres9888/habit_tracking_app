Pro rows get a warm parchment background, PRO badge by the label, and a gradient green pill. Tapping a free row opens the editor; tapping a Pro row either opens the editor (if subscribed) or opens the upgrade sheet.

Why this hybrid

  • UX: Free rows are 100% tappable — biggest possible hit target on mobile, "Tap to edit ›" tells the user exactly what's coming. No micro-aiming.
  • Monetization: The gradient pill + PRO badge + warm parchment row creates a visual upsell prompt that doesn't require a modal. Users self-select into curiosity-tapping.
  • Hierarchy: Only Pro rows get the loud green pill — so the dark-green "Create Habit" CTA at the bottom still wins as the primary action. Nothing competes with Save.
  • Flexibility: The Pro affordance is opt-in per row. Ship the all-free version today; flip a row to tier: "pro" later without redesigning anything.
