Design rationale

1 · Education is sequenced, never stacked

S1 frames the outcome in one sentence, S3 proves the habit, S4 teaches sticking only after commitment, S5 sets the return loop. Each lesson arrives at the only moment it's actionable.

2 · The fast path is sacred

Every screen has a one-tap "+ Add"; education catches up post-add as a dismissible sheet. Time-to-first-add stays at one tap while stick-mechanics still reach every first-time adder.

3 · Warmth for emotional choices, minimalism for rational ones

Gradients and goal colors appear where the user chooses an identity or celebrates; compact white rows appear where they compare options. Color carries meaning, not decoration.

4 · Start-small at the moment of commitment

The primary CTA is the tiny version ("one slow, mindful breath"); the full version is a text link. Trades day-1 ambition for day-7 survival — the retention metric that drives revenue.

5 · One decision per screen

Outcome → first habit → start size → cue → (optional) next habit. Everything else is glanceable in one line or less.
