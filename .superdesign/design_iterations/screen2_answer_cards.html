What changed

  • Dashed box → 3 answer cards. Each card is shaped like the answer screens 3–6 will fill in. The user sees the literal shape of what's missing.
  • Redacted values (?? days, —/—, no idea) make "You don't know" visceral instead of just stated.
  • Dropped "You're lost." — redundant with headline.
  • Closing line updated from "No map. No markers. So you quit." → "No map. No safety net. So most people quit." Externalizes blame ("most people"), and "safety net" picks up "what if I miss a day?".

How this serves conversion + retention

  • Conversion: visual matches what the user has actually wondered. Less reading, more "oh, that's what I want."
  • Retention: each card is a label for a real feature — when the user later sees "21 days to Gold" or "Day 4/21 · Iron" or "Strength 78 → 76 (dent)", they recognize each as the answer to a question they had on screen 2. That recognition compounds trust over weeks.
