Usage Rules

  • DO: Use accent colors at 15-20% opacity for backgrounds
  • DO: Keep stone-800 as primary card background
  • DO: Use stone-400 for secondary text
  • DON'T: Use pure black (#000) or pure white (#fff)
  • DON'T: Mix cool grays with stone palette
  • DON'T: Use blue as primary (conflicts with system UI)

Spacing Units

// Base unit: 4px

cardPadding: 16 // 4 units
cardGap: 12 // 3 units
listGap: 16 // 4 units
screenPadding: 16 // 4 units
accentBorderWidth: 4 // 1 unit

Always use multiples of 4px for spacing. This ensures visual consistency and aligns with the native 4-point grid.

Note: Use stone-500 as the shadow color base (not black) for warmer, more cohesive shadows in dark mode. Keep opacity low (6-15%) for subtlety.
