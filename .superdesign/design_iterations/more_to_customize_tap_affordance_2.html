“More to Customize” — make the box obviously openable

Six variants ranked by tap-affordance strength. Each preserves the app’s warm-minimal language. The current pill reads as a label because it lives in the same horizontal band where sibling section labels (Choose an icon / Pick a color) are also centered and tertiary-colored — context kills its button-ness.

Why the current pill fails: centered uppercase tertiary text + a chevron looks like a passive header. Users skim and treat it like the labels above it. The fix is either change the shape so it can’t be mistaken for a header or show what’s inside so the value is visible before tap.

V1 · iOS settings row
Full-width row · trailing chevron

The pattern every iPhone user has tapped 10,000 times. Left icon, title + subtitle, chevron on the right. Unmistakably tappable.

Recommendation: V1 (iOS settings row) for safety, V2 (Preview + Edit) for delight

V1 is the safest pick — it's the pattern users tap dozens of times a day in iOS Settings, so there's no learning curve and no risk of misreading it as a header. It walks back some of the visual minimalism we landed on, but the tradeoff is worth it for clarity.

V2 is the more interesting bet — it surfaces what's actually customizable (Forgiving · Classic · 30-day) as chips, so users learn the feature without tapping in. The EDIT pill removes any doubt that the card is interactive. Best long-term, but slightly more visual weight.

Skip V3 (color competes with Save), V4 (handle over-promises drag), V5 (dashed border introduces new primitive), V6 (split tap targets).
