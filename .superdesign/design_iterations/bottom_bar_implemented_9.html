→
Templates color

→
Progress counter
None → "1 of 3" below Add button — drives completion momentum without UI clutter Engagement
→
Badge dot
#ef4444 red (alarming) → #F59E0B amber (inviting) — feels like a reward to discover, not an alert Revenue
→
Add button shape
Circle (r=24) → Squircle (r=16) — matches card system, 52px tap target Engagement
→
Color hierarchy
Green + purple + gray → Green (create) · Gold (discover) · Neutral (configure) Retention
→
Bar surface
Flat rgba overlay → Parchment-tinted blur(20px) — content shows through, feels native Retention
→
Typography
System font 12px → DM Sans 13px — matches app caption scale Retention
→
Settings pill
Transparent ghost → Subtle fill + shadow — more discoverable for upsell surface Revenue
