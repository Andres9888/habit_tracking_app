Improvements with UX Evidence

High Impact

ISC-7: Thicker Ring Track (3px → 4px)

Increase stroke width to 4px for a 1:11 stroke-to-diameter ratio. The track becomes more visible as a "container to fill," triggering the Endowed Progress Effect. Apple Watch uses 1:6 for wearables; 1:11 is optimal for 44px mobile rings.

Endowed Progress Effect (Nunes & Dreze, 2006) — visible empty track = "progress already started" → 34% vs 19% completion. Pre-attentive Processing (Treisman, 1985) — thicker strokes detected in <200ms.

High Impact

ISC-8: "TODAY" Label Replaces Weekday

Replace "Wed" with "TODAY" for the current day. Provides instant temporal orientation without mapping weekday names. Uses amber color + heavier weight for dual-coding (color + text).

Dual Coding Theory (Paivio, 1971) — verbal + visual = two memory traces. Change Blindness mitigation — semantic labels resist overlooking better than contextual ones.

Medium Impact

ISC-8: Amber Border Stroke on Today

A subtle 1px amber border outside the track creates a clear focal anchor beyond the breathing glow, which may be too subtle on some screens or in bright light.

Gestalt Figure-Ground — amber boundary separates today from shelf. Goal Gradient Effect (Kivetz, 2006) — visible "boundary to fill" increases effort near completion.

Medium Impact

ISC-6: Uppercase Weekday Labels

"Mon" (mixed, 11px) → "MON" (uppercase, 10px, 600 weight, 0.5px tracking). Uniform letter height creates consistent visual rhythm. Muted color subordinates labels to ring content.

Information Hierarchy — labels subordinate to data. Uniform cap-height creates scannable rhythm across the strip (Banner & Starkweather, 1972).

Medium Impact

ISC-10: Dashed Track for Future Days

Future days use dashed stroke (4px dash, 4px gap) instead of solid. Creates pre-attentive distinction: solid = actionable, dashed = upcoming. Reduced opacity 0.3 (from 0.4).

Pre-attentive Feature (Healey & Enns, 2012) — stroke pattern processed in parallel vision (<200ms). Reduces cognitive load for past/future distinction.

Medium Impact

ISC-12: Compassionate Missed Day

Past days with 0 completions: opacity 0.55 + small neutral dot below ring. No red, no X, no shame. Acknowledges missed day without punishment.

ISC-A-1 compliant. Self-Determination Theory (Deci & Ryan) — autonomy-supportive feedback preserves intrinsic motivation vs controlling/shaming cues.

Low Effort, Quick Win

ISC-11: Rounded Connector Arms

Add border-radius: 2px + increase height 3.5→4px. Rounded ends continue the circular motif. Streak chain reads as one connected unit.

Gestalt Continuity — rounded shapes match ring silhouette, creating cohesive visual language.

Low Effort, Quick Win

ISC-16: Bolder Today Number

Today's number: font-weight 800, 15px (from 14px/700). Creates subtle size hierarchy: today > past > future.

Weber-Fechner Law — JND for weight at this size requires meaningful step. Combined with amber = multi-channel emphasis without new UI elements.

Accessibility Compliance

ISC-14

Touch Targets: 44px minimum

Ring containers are 44×44px (WCAG 2.1 SC 2.5.5). Flex-1 layout extends actual tap areas to ~60-70px cell width, exceeding the minimum. No changes needed.

ISC-15

Color Contrast: WCAG AA

Light: Amber #7D5907 on #FAF8F5 = 6.36:1 ✓. Day numbers #2D2A26 on #FAF8F5 = ~12:1 ✓. Muted labels #9CA3AF on #FAF8F5 = 2.8:1 (WCAG 1.4.3 exempt: incidental decorative text).
Dark: Amber #E8B94D on #1F2937 = 5.2:1 ✓. Primary text #F9FAFB on #1F2937 = 14.7:1 ✓.
