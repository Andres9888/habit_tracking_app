What Changed

  • 3 separate horizontal pills → 1 card with 3 equal flex: 1 columns
  • Each column stacks vertically: emoji, value (large monospace), label
  • Thin 1px separators between columns using colors.border
  • Card uses borderRadius: 16 + shadows.card to match tabs and content cards
  • Active streak: green value text + subtle green circle behind emoji (not full-pill flood)
  • Values at 20px JetBrains Mono (up from 13px) — the primary data is now the hero of each column

Why It Fits

  • No clipping possible — flex: 1 columns divide available width equally on any screen
  • Visual consistency — card shape matches tabs card and heatmap/strength cards below
  • Design tokens — uses colors.card, borderRadius.card, shadows.card, fontFamilies.monospace
  • Hierarchy — large numbers as focal point, emoji for visual interest, subtle labels for context
