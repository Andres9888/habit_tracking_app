Design decisions, in brief

Greeting over skeleton. The "Good morning, Andres" eyebrow uses the primary color at 700 so it reads as a signal, not decoration. Pairs with a Literata headline that names the metaphor ("first chain") so we teach the product language on the first surface.

Ghost card teaches the payoff. A dashed preview card shows exactly what a populated habit will look like at day 4 — a completed chain with today pulsing. This does the work the onboarding carousel was supposed to do, in the context of real use, not a detachable tutorial.

Single primary CTA. Filled green (#059669), 56px tall, the one unambiguous next step. Secondary template link in text-weight green underneath. Zero ambiguity about where to tap.

Motivation surfaces earn their entry. Three cards (WOOP, Vision, Why) sit under an optional "Get grounded in 2 minutes" divider — a side-path for users who want the motivational scaffolding before the mechanical one. Card rows are 120px min-height + have explicit time costs so users know what they're committing to. Lucide icons on filled gradient tiles (not emoji) for category identity.

FAB teaches itself. Two scale-nudge animations at t=1.5s and t=7s + a single expanding ring on first mount draw the eye to the FAB if the user doesn't engage the primary CTA. The amber dot on the templates icon becomes green (primary-500) because this IS new content, aligning semantics.

What I'd want to test: whether the ghost card reads as "preview, not real" at a glance, or if users try to tap it. Dashed border + "PREVIEW" eyebrow + zero shadow are the current cues. If user tests show confusion, add a light grayscale to the card and a subtle "tap to see filled version" affordance.
