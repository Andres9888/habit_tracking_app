Pill Tab Refinement

You like the chip/pill direction (F from earlier). Now we polish it so it aligns with the rest of the app. Each card shows the tab in actual context (hero above, content card below) so you can see how it relates to nearby surfaces.

My hypothesis on what feels off: The current version (A) has a track that's lighter than the canvas (#FAF8F5 on #F5F1ED). Everywhere else in the app, surfaces go darker than canvas (#EDEAE5 cards on #F5F1ED canvas). So the tabs' plane hierarchy is inverted from everything else — your brain reads it as "wrong." Variants B, C, E, F, G fix this by making the track match or be darker than the canvas.
