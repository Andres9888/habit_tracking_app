The Big Shift: Goals = Hero, not a hidden trigger

Instead of leading with "browse our content," the page now leads with "What do you want to change?" — putting transformation first. Every other section becomes a fallback path for users who already know what they want.

Why this works: Most users opening a habit library don't think "I want a habit in the morning_routine category." They think "I want to sleep better" or "I want more energy." Goals match how users actually frame their problem.

Key Design Shifts vs V1

Header copy
"Habit Library" → "What do you want to change?" — frames the page as a transformation tool, not a content catalog.
Goal cards
5 small grid cards → 5 prominent transformation cards with featured time-aware hero, outcome promises, and habit count.
Goal copy
"Sleep Better" → "Sleep deeper · Wind down, rest fully, wake refreshed" — outcome-driven, not category-driven.
Featured time-aware
Separate hero gradient → Merged into goal grid as the featured/highlighted goal card. One hero, not two.
Search position
Top of page → Below goals with copy "Or search for a specific habit…" — repositioned as the alternate path.
Categories
2-column grid taking ~300px → Single "Browse all categories" link row taking ~60px. Categories are still discoverable but not competing with goals.
Quick filter chips
Removed from main view → Available inside goal drill-in view only. They're a category-filtering tool, not an entry point.
Trending
Stays as vertical inline cards — for users who want to add a popular habit without going through goals.

Each Goal Card Tells a Transformation Story

Anatomy of a goal card:

1. Big emoji icon — instant recognition (😴 ⚡ 🧘 🎯 💪)
2. Outcome verb phrase — "Sleep deeper" not "Sleep"
3. Promise / transformation — what life looks like after ("Wind down, rest fully, wake refreshed")
4. Habit count — proves there's substance ("8 habits")
5. Tap-to-explore arrow — clear forward affordance

The featured goal (full-width row at top) rotates by time of day — morning shows "Wake up energized," evening shows "Sleep deeper," etc. — same time-aware logic as the current FeaturedCollection, but now it lives inside the goal system.

What Happens When User Taps a Goal

Tapping a goal card opens a focused drill-in view showing only habits relevant to that transformation. The existing CategoryDrillView can be reused with multi-category filtering — Sleep Deeper goal pulls from {sleep, recovery, breathing} categories (already mapped in goalCollections.ts).

This means: no new backend, no new data structures. The cross-category goal grouping is already in GOAL_COLLECTIONS with `categories: string[]`. We just need to render them prominently and route the tap to a multi-category drill view.

For Users Who Don't Know Their Goal

Three escape hatches preserved in priority order:

1. Search ("Or search for a specific habit…") — for users who know the exact habit name
2. Trending (3 inline vertical cards) — for users who want social proof
3. Browse all categories (single link row) — for power users who think in categories
4. Curated Packs (horizontal scroll) — for users who want pre-built bundles

Each path is still 1-tap accessible, but goals get the visual weight that matches their importance as the primary discovery flow.

Implementation Impact

Files that change:

• MainBrowseView.tsx — major reorder, new hero question header
• GoalCollectionGrid.tsx — redesign cards (bigger, transformation copy, featured row)

• FeaturedCollection.tsx — could be removed or merged into goal grid
• CategoryGrid.tsx — convert to compact "Browse all" link
• QuickFilterChips.tsx — move to drill-in views only
• StartHereCard.tsx — could be removed (goals serve this purpose now)
