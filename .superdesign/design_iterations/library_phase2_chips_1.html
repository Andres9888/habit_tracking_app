Implementation spec at a glance

⚡ QUICK CHIP
Active style: bg #FBBF24, border #F59E0B, text #78350F.

Filter rule: estimatedMinutes ≤ 5 if set, else regex on name+description matches 1-5 min, “quick”, “brief”, “30 sec”, “micro”, “moment”, “tiny”.
🔥 HIGH ROI CHIP
Active style: bg #FEE2E2, border #EF4444, text #7F1D1D.

Filter rule: popularityScore ≥ 85. Tunable constant (HIGH_ROI_THRESHOLD). Composes with search + other chips through the existing .filter() pipeline.
›  SCROLL AFFORDANCE
Fade: 32 px → 64 px wide, soft 3-stop gradient.

Chevron: faint › glyph at right edge, color --text-tertiary, gentle 2.4 s pulse animation. Both pointerEvents="none" and hidden from VoiceOver. Row paddingRight bumped 40 → 72.
