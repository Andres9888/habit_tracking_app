Improvement Audit

Animations & Transitions
High Toggle row pulse — Add green background pulse (0.4s ease-out) when any toggle is flipped. Currently only the Switch widget animates; the entire row should respond.
High Conditional row expand — Notification sub-rows (time picker, premium upsell) currently pop in instantly. Wrap in LayoutAnimation with 300ms spring for smooth height transition.
Med Header scroll shadow — Add border-bottom or subtle shadow when scroll offset > 0. Use onScroll + Reanimated useAnimatedScrollHandler.
Med Account sub-section stagger — AccountSection renders 4 sub-sections (Account, Premium, App, Legal) simultaneously. Break them out into individual <Animated.View> blocks with continued stagger delays (180ms, 240ms, 300ms, 360ms).
Low Badge bounce-in — Archived habits count badge should enter with ZoomIn.springify() for subtle delight.
Low Close button exit — Add FadeOutUp exiting animation to header when modal dismisses.
Haptic Feedback
High Toggle → Medium impact — Currently all interactions use Light. Toggles deserve Medium for a more satisfying on/off feel.
High Destructive → Heavy impact — Sign Out and Delete Account should use Heavy haptic to signal gravity of the action.
Med Selection → Selection style — Time picker and sort order taps should use Haptics.selectionAsync() instead of impactAsync.
Premium Monetization
High Premium CTA gradient card — Replace flat card with gradient background + shimmer animation. This is the primary conversion surface — it should feel premium and draw the eye.
Med PRO badge pulse — Subtle 2s ease-in-out infinite scale pulse on the PRO badge to draw attention without being annoying.
Med Break Premium out of AccountSection — Currently nested inside AccountSection. As a standalone staggered section, it gets its own visual prominence and entry animation.
Consistency Fixes
High Toggle rows missing AnimatedPressable — SettingsRow.tsx:136 returns raw content for toggle/info types. While toggle rows shouldn't scale on press (the Switch handles interaction), they should still get the row pulse feedback.
Med Chevron micro-translate — On row press, chevron should shift right 2px with spring animation, consistent with how the app's navigation rows behave elsewhere.
Low Dark mode icon colors — When toggling dark mode, the icon badge colors should transition smoothly rather than instant swap.
