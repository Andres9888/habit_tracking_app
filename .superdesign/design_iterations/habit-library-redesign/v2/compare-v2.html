Habit Library — v1 vs v2

Side-by-side comparison of v1 redesign mocks (left) vs v2 review-feedback updates (right). Same dark mobile frame, ~390px width.

v2 updates Based on review feedback.
v1 — original redesign v2 — review feedback

What changed & why

  • Header: "What do you want to work on?" → "Start one small habit today" — Reduces decision paralysis. The old header implied a big commitment; the new one frames it as low-stakes and invites a single action.
  • Subtitle: "Pick a path" → "Pick one that feels easy — you can always add more." — Reassures new users they won't be locked in, lowering the bar to first action.
  • "Not sure? 30-sec guide" → "Help me choose" — Simpler label; same floating pill, same guided-picker destination. "Help me choose" is clearer and shorter.
  • Added GoalCollectionGrid — 2×2 visual grid (Health, Focus, Sleep, Morning) gives browse-by-goal a more scannable layout before the "Browse all" link.
v1 — three-question form v2 — progressive disclosure

What changed & why

  • Complete structural rework: form-then-results → progressive results — v1 showed all 3 questions upfront in a left panel and results in a right panel. v2 shows only Q1 (area of life), with results appearing immediately below as the user taps a category. This reduces effort-to-first-result from ~3 taps to 1.
  • "Refine your results" expandable section — Q2 (time) and Q3 (style) are collapsed by default. Users who want more precision can expand; users who are happy with area-only results can skip. This respects Hick's Law — fewer choices visible = faster decisions.
  • Each result card shows "Why this matches you" line — Moves the match reasoning inline into each card instead of a separate MatchReasonList. Reduces eye-tracking distance and makes the value proposition per-template immediately clear.
  • Show 3 initially, "Show more" to expand — Prevents overwhelm. The v1 showed all 3 in a separate panel; v2 shows 3 inline with a progressive-load button for 3 more.
  • Escape routes: "Edit answers" + "Browse all instead" — At the bottom of results. Ensures users never feel trapped in the guided flow.
  • Adapted to dark mobile frame — v1 was desktop-only light theme. v2 matches the app's actual dark mobile UI for realistic preview.
v1 — confidence detail v2 — updated detail

What changed & why

  • Back button (← instead of just ✕ close) — Supports view-stack navigation. Users can return to the guided picker or browse list without losing context. The v1 close button implied dismissal; the back button implies a breadcrumb trail.
  • "Pairs well with" sourced from templatePairings — v1 used the generic "habitPairings" label. v2 explicitly notes "From templatePairings" to clarify the data source and distinguish from user-created pairings. Subtle copy change but important for component architecture clarity.
  • Adapted to dark mobile frame — v1 was a desktop light-theme wireframe. v2 matches the actual app's dark mobile UI with the same visual language as the other screens (slate-950 background, emerald accents, rounded cards).
  • Same confidence-first layout preserved — Promise → Feasibility → Why it works → How you'll do it → Identity → Customize accordion. The structure was validated and unchanged.
v1 — success next-step v2 — full-view success

What changed & why

  • Full-screen view instead of a toast or inline card — v1 used a desktop-layout with side panels. v2 takes over the entire screen after import. This creates a clear "moment" — the user just did something meaningful and the UI celebrates it without distracting them with layout chrome.
  • Clear "What's next?" action list — Four structured next steps: Set reminder, Build a stack (pairing), Share, Add another. Each is a tappable row with icon, title, and subtitle. v1 had similar recommendations but they were text cards, not interactive action rows.
  • "Done" button closes the library entirely — Sticky footer with a "Done" button. Users can explicitly dismiss the entire library flow and return to their daily view. v1 had "View today's plan" which is similar but the naming was ambiguous.
  • First-import variant — Shows a highlighted amber card: "First habit — nice work 🎉" with "Take the 30-second guide" as the primary CTA. Activated via ?first=true query param. This emphasizes the guided picker as the natural next step for users who just added their very first habit.
