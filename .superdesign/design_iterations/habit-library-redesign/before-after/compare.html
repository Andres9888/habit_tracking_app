Habit Library — Before vs After

Side-by-side structural comparison of the current app vs the redesign mocks. Same Tailwind, same dark mobile frame, same ~390px width.

Mocks only No app source modified.
Before — current app After — redesign

Key changes

  • Adds a floating "Not sure? 30-sec guide" pill — a guided-picker entry point. The current app has no such affordance: users must scroll the starter list or browse by goal cold.
  • Tightens StarterHabitList copy and visual rhythm — same "Start with these 5" framing, but the redesign collapses to 3 visible rows so the guided-picker pill remains the dominant next step.
  • Same MainBrowseView shell (header → search → chips → starter pack → "Browse all categories"). Structure is preserved on purpose; the redesign is additive at this level.
Before — current app After — redesign

Key changes

  • Adds a persistent "Help me choose" pill for returning users too — current app drops them straight into goal/popular browsing with no triage path.
  • Simplifies the FeaturedGoalCard CTA — current shows "Start your path → · 12 habits inside"; redesign trims the count copy and emphasizes the inline 3-starter row as the real CTA.
  • Compresses the popular rail — current uses richer TrendingCard cells (icon + trending tag + Add button per card); redesign reduces to titles for scanning, deferring "Add" to the detail screen.
Before — TemplatePreviewModal After — Confidence detail

Key changes

  • Reframes the sheet from "customize this template" to "should you commit to this habit?" — current opens straight on icon/color/reminder/advanced options; redesign opens on a Promise card with feasibility meta (time, style, difficulty) and primary "Add habit" CTA.
  • Adds confidence-building sections: Why this works (with a research citation), How you'll do it (cue + start-small + tip), Who you'll become (identity statement). None of these exist today.
  • Demotes customization — name, icon, color, reminder, advanced options collapse into a single Customize accordion. Reduces the cognitive load on the moment of decision.
  • Adds "Pairs well with" — habit-stacking suggestions, absent in the current modal.
Before — TemplateAddedToast After — What's-next surface

Key changes

  • Replaces a transient bottom toast with a dedicated "What's next?" surface — current behavior dismisses in ~5s with two actions ("View my habit" / "Add another"). Redesign keeps the user in a deliberate post-add flow.
  • Promotes second-action prompts: set reminder time, build a stack (pair with another habit), share, add another. Today these are buried in the detail modal or require the user to navigate manually.
  • Keeps the celebratory tone but moves it from confetti overlay to a calm, persistent green confirmation card, reducing motion-heavy interruption while still confirming the win.
