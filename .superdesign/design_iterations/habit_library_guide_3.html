How prescription habits get picked (and what to call it)

Hand-curated, not algorithmic. One static config file, five entries — each written once, with the science in hand. Popularity can't write an insight line; an editor can. The label rotates away from "Starting point" — proposed: "Your way in". 
// prescriptions.ts
{
  goalId: 'sleep-better',
  label: 'Your way in',
  insight: 'Start with a wind-down, not a wake-up',
  why: 'Most sleep problems are evening problems. These two habits fix the input.',
  steps: [
    { templateSlug: 'screens-off-by-10', reason: 'Blue light delays melatonin ~90 min' },
    { templateSlug: 'read-before-bed',   reason: 'Replaces scrolling, drops heart rate' },
  ],
}
Later (v2, optional): one refinement question per goal — "Falling asleep or staying asleep?" — branching to a second prescription per goal. Still static config, still no backend.
