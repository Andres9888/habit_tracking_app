Privacy · Terms · What's new · v2.4.1 (45)
1 Keep the name. Show the value.
“Daily reminder” would scan faster and lie. This is still a streak-slip nudge. The row keeps Streak reminders; the subtitle stops selling (“Nudge before…”) and reports state: On · 8:00 PM / Off. Time still edits in the inset — same as today.
2 Collapse completion sound
Sort already hides behind a tap. Sound is the last always-open picker on the page — three pills for a preference you set once. After: value on the row (Chime), picker expands on tap. Same tones. No rename to “Sounds & haptics” — haptics aren’t a setting here.
3 Support: 4 rows → 2
Rate and Share are one intent (both open a system sheet). Merge into Love Chain Day? → action sheet (Rate / Share). What’s new is a changelog, not a setting — it moves to the footer with Version. Feedback stays; it’s the only Support job that belongs here.
4 Premium stays. It has to work.
The dark banner is the conversion surface. The reminders-inset crown is already gone (quiet text link ships today). The actual bug: onPremiumUpsell is often unwired, so Upgrade can no-op. This pass wires it. No new gating, no new rows from schema leftovers.
5 Explicitly not this pass
Look & Feel, hero, Calendar look, Account, export placement, app lock, reduce motion, text size, search, accordions-as-IA. Dead search/accordion code can be deleted as hygiene without a visual change.
Net: Support 4 → 2. Sound picker off the resting scroll. Reminder row tells the truth.
Look & Feel and Habits are already the right size — leave them.
Zero features lost. Rate, share, changelog, tones, reminder time all stay reachable.
