Design options
A
Trailing chevron REC
A single › icon at the card's right edge, vertically centered. Universal iOS/Android disclosure pattern. Minimal footprint, zero extra text.
B
View details row
Explicit "View details ›" text below the meta pills, separated by a hairline. No ambiguity — tells the user exactly what happens. Takes more vertical space.
C
Press animation only
Scale to 0.98 + opacity 0.9 on press. Gives tactile feedback but no pre-tap signal. Best used as a complement to A or B, not standalone.
All three options can be combined. A + C is the recommended pairing — the chevron signals tappability before any interaction; the press animation makes the card feel alive on touch.
What changes in code
Option A — add ChevronRight icon (lucide-react-native) as third column in topRow inside TemplateListCard.tsx. ~5 lines.

Option B — add details-row View below CardFooterMeta. ~8 lines across 2 files.

Option C — change Pressable style prop to function returning scale/opacity on pressed state. ~3 lines.
