“More to Customize” — make it unmistakably tappable

The current tile reads like an info card because the chips preview data and the EDIT pill is small. To say "this is a control," we need a primary affordance — a button, a verb, or an arrow that can't be mistaken for decoration. Four options, ranked.

1 · Primary CTA button
Chips on top, real green button on bottom

Add an explicit primary CTA button at the bottom of the tile. The user can't miss it — it looks exactly like every "Continue/Save" button they've ever tapped.

My pick: 1 · Primary CTA button

Adding an explicit green "CUSTOMIZE ›" button at the bottom of the tile is the strongest "tap me" signal — it looks like every confirm/continue button the user has ever tapped. The chips still act as a preview of what's inside. Risk: it shares brand green with the Save button at the top of the modal, so we'd want to confirm visual hierarchy stays right.

Runner-up: 2 · Verb + primary border — less visual weight than a button while still being explicit.
