Fix: Header X collision on Pro Max FIX

On iPhone 16 Pro Max the modal close X overlaps the title text. Fix is surgical — reserve right-padding on the title & subtitle so they naturally leave space for the X overlay.

BEFORE
Title spans full width, X button overlays the text at top-right. Works on 6.1" iPhone, cuts on Pro Max.
AFTER
padding-right: 40px on title & subtitle reserves the X zone. Title wraps or truncates gracefully on any screen.

Add back: Big category tiles ADD

Replaces the compact "Browse all categories" link with the 2-column category tile grid you liked. Tiles live between the pill search and Trending — positioned as "if goal framing doesn't click, browse by type instead."

Placement logic: Goals (what do I want?) → Search (specific habit) → Categories (what type?) → Trending (what's popular?). Each section is a different lens on the same 200+ habit library.

Polish: Tiles keep the colored-left-border accent from the v1 mockup, emoji + label + count, 92px min-height (compact vs original 120px).

Polish: Pill-style compact search POLISH

Shrinks search from a 44px-tall full-size bar to a 38px pill. Rationale: search is now the secondary entry point (goals are primary), so its visual weight should match. Also reduces scroll-depth by ~8px.

Bonus fix for the X cutoff — pill has text-overflow: ellipsis on the input text so long queries clip cleanly instead of running under the clear-X.
