Change 1

Pre-open 2 habits per category

Why: v5 was too "enterprise" — closed cards force a tap for any info. Showing 2 habits gives the user a flavor of what's inside without forcing expansion.

Why 2 (not 3): 3 habit rows + header ≈ 240px card — 7 cards won't fit one screen. 2 habit rows + header ≈ 180px — 4 cards per screen, all categories in ~2 scrolls.

Implementation: in AccordionCategoryCard.tsx, always render the first 2 habits. When expanded, render the rest inline + flip chevron. Replace "Show all N →" with a hide action when open.

Change 2

Merge 3 "Other" categories into 1

Why: relationships (5 habits), environmental_design (3), and subtraction (2) aren't in CATEGORY_META, so each gets labeled "Other 📌" and renders as a separate card — 3 visually identical cards in a row.

Implementation: in useGroupedTemplates.ts, any template whose category isn't in CATEGORY_META gets merged into one 'other' key. Export an isKnownCategory helper from categoryMeta.ts. Result: one "Other" card, 10 habits total.

Combined effect

From a ~7-card stack of fully-collapsed headers → a ~5-card stack where every card already shows useful content. Roughly the same vertical height, dramatically more glanceable.

Scroll distance to see every category: ~2 screens (was ~3 in v5, ~7+ in v3 top-3 preview).

What's next if approved

Two small code edits:

  • useGroupedTemplates.ts — collapse unmapped categories into 'other'
  • AccordionCategoryCard.tsx — always render first 2 habits, conditional rest on expand

Plus a small export from categoryMeta.ts. All files stay under 100 lines.
