1

"Continue building" rail for returning users

The page currently treats every visitor as new. For users with active habits, swap the page header to "Pick up where you left off" and surface a horizontal rail of in-progress habits with their weekly streak. New users see the existing "What do you want to work on?" header and skip straight to the goal grid.

Conditional · driven by activeHabits.length
2

Make "Today's pick" actually rotate

The featured goal already has a "Today's pick" badge — wire it to a daily seed (e.g. day-of-week → goalId mapping) so it visibly changes. Add the weekday name to the badge ("Today's pick · Friday") to make the rotation legible without forcing the user to remember yesterday.

Trust · stop over-promising
3

"Tracking" pill on already-imported cards

If a user already tracks a habit shown in Popular or any goal collection, the card should show a green "✓ Tracking" pill (and use a tinted surface) instead of letting them re-import. Tap behavior changes from "Preview to add" → "Open habit detail." Eliminates the "did I already add this?" confusion.

Wiring · importedTemplateIds already plumbed
4

Cleaner hierarchy after Packs hidden

With Premium Packs gone, the page reads as a clean three-act structure: Goals → Popular → Browse by Area. No paywall surface in the middle of free discovery. Browse-by-area gets a tighter 3-up grid so all 14 categories fit in 5 rows instead of 14 separate horizontal scroll rails.

Already shipped · this branch
5

Post-import toast with "Add another?" nudge

After preview → import, slide a confirmation toast in from the bottom: "Cold shower added" with a "Track it daily" sub and a primary Add another button. The card behind animates to the green Tracking state. Single-visit imports today are 1; with this nudge most users add 2–3 in a row. Toast auto-dismisses in 4s but the tracking state persists.

Retention · highest expected impact
