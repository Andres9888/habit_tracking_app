Jan 2026

Improvements:

  • • Big CTA button - Primary action prominent
  • • Cleaner header - Less cramped, shows start date
  • • Simplified stats - Inline format, no redundancy
  • • Motivational header - Weekly progress on calendar
  • • Stronger completed days - Solid fill vs subtle bg
  • • "Building..." label - Friendlier than "Weak"

Recommended Changes

1. Prominent CTA

Move "Mark Done" from cramped header to a full-width button below the header. This is the primary action users come to this screen for.

2. Friendlier Labels

Replace "Weak" with "Building..." or "Just Starting" - less discouraging for new habits. Users need encouragement, not judgment.

3. Simplified Stats

Replace 3-column stats row with inline format. When values are the same (8%, +8%, +8%), it looks redundant. Show only meaningful differences.

4. Weekly Progress

Add motivational header to calendar showing weekly completion count. "2 days this week!" with a goal creates achievable micro-targets.

5. Stronger Completion

Make completed days more visible with solid color fill instead of subtle background + dot. Celebrate wins more visibly.

6. Context in Header

Show "Started Jan 1, 2026" under habit name. Gives context about habit age and helps users feel progress over time.
