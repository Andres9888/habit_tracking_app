Why this is better

  • Month is the hero: At 22px Literata bold, "March" becomes the first thing you read — it dominates the header without being garish.
  • No new UI elements: This replaces the existing date row rather than adding to it — same amount of content, better hierarchy.
  • Day detail as subtext: "Thursday, 5th" is secondary information (you know today is today) — demoting it to 13px makes room for the month to breathe.
  • Week number context: "Week 1" alongside the day provides month-position context that the current UI completely lacks.
  • Consistent with iOS Calendar: Apple's Calendar app uses this exact two-line pattern (month big, day small) — users already expect it.
