Improvements: Rows now have a lighter background that pops against the card. Bright green EDIT › pill is unmistakable. Helper caption tells users to tap. Each row has a one-line explanation of what it does. Growth Type is demoted to a small pill so it no longer looks like a button.

What changed

  • EDIT pill replaces the subtle chevron. Green, high-contrast, unambiguous tap affordance.
  • Row background lightened against the section card so rows visibly separate from the container.
  • Press feedback added — rows tint primary-green and dip in opacity when pressed (try hovering above).
  • One-line description on each row explains what the option actually does, in plain language.
  • Section helper caption — "Tap any option below to customize how this habit grows."
  • Growth Type demoted from a full row (which looked like a button) to a compact pill, removing the visual conflict.
