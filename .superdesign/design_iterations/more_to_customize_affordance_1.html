“More to Customize” — make it obviously tappable

The flat divider now reads like Choose an icon / Pick a color — but those don’t open anything; this does. Below are four affordance options that preserve the cleaner alignment we already shipped, while signalling interactivity. All keep the centered placement, the uppercase / letter-spaced label, the tertiary text color, and the chevron.

My recommendation

Variant A — pill button. It’s the lightest of the four, reuses an existing app pattern (the Growth-Type pill that lives inside this very section), and gives a clearly defined tap surface without re-introducing the heavy card. Variant B is a strong second if you’d rather have a wider tap target.
