Recommendation: B + C Hybrid → 9.5

Ship B's normal state (burnished gold Explore, progress ring, ghost Settings) — it scores 9.1 with zero new patterns.

Add C's contextual pill swap on all-done only. When all habits are complete, Explore becomes "Insights ›" in premium purple. This is the highest-value moment — user just got a dopamine hit, and "Insights" promises to show them their progress data. It bridges celebration → premium feature discovery.

The B+C hybrid scores 9.5 by combining B's consistency (9.5) with C's Premium Zone architecture (9.5). The pill swap is the only new pattern introduced, and it only appears in the celebration state — so the consistency cost is minimal (users see it briefly, once per day, at their happiest moment).

Animation spec for the pill swap: Explore pill fades out (opacity 1→0, 150ms ease-out) while Insights pill fades in (opacity 0→1, 280ms ease-out + scale 0.95→1 spring d:18 s:150). Uses standard exit/entrance timing — no new spring config needed.
