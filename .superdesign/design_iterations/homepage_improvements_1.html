Recommended Implementation Sequence
Ordered by impact per engineering hour. Phase 1 is pure UI work with no backend dependencies. Phase 2 needs streak/history data. Phase 3 needs an analytics engine.
Phase 1 · This week (no backend)
1. All-Done Celebration — greeting text swap + card glow + confetti overlay. Builds on existing useCelebrationState hook. ~2 components.
4. Smart Greeting — enhance getGreeting() to accept progress ratio + time. Zero new components, just logic in ProgressGreeting.tsx.
5. Quick Win Highlight — add isQuickWin prop to HabitCard. Determine easiest habit by streak length (longest streak = most automatic = quickest). ~1 new hook.
Phase 2 · Next sprint (streak data)
2. Streak Guardian — new StreakGuardCard component. Shows when time > 6pm AND unfinished habits have streaks > 7 days. Premium: "Protect" button for streak shield purchase. ~2 components + 1 hook.
3. Strength Bars — compute strength from streak history (0-30 day mapping). 3px bar at card bottom, color-coded. Premium: per-habit analytics deep dive. ~1 component + theme tokens.
Phase 3 · Future (analytics engine)
6. Premium Insight Slot — requires pattern analysis (best time of day, most consistent days, completion correlations). Show 1 free insight daily, PRO badge for unlimited. Composable header slot system for future V2-V8 variants. ~3 components + analytics service.
