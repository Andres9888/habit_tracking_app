S4 · Make It Stick — unchanged

  • Kept exactly as shipped: cue chips persist to the habit, 66-day expectation, identity line, skippable.
  • Appears once, after the first add, regardless of which surface the add came from.
Habits before goals The carousel sells specific, concrete habits first — most users add from "Popular" without ever picking a goal. Goals become a browse filter, not a gate.
One layout per altitude Carousel = discovery (rich), detailed rows = comparison inside a goal (scannable), details page = commitment (deep). Each screen earns its density.
Details always one tap away Every habit surface (card, row) has both + Add and a path to Details — fast path and learn path never compete.
Nothing prescriptive No "first step / then build" sequencing. Order by popularity, let the user choose; education lives on the details page where it's wanted.
