4. Gating logic — before vs after

Current (hard paywall)

AuthGate state machine:
  unsigned → WelcomeScreen
  signed-in + onboarding incomplete → OnboardingFlowV2
  signed-in + onboarding done + no-sub → PaywallScreen (BLOCK)
  signed-in + onboarding done + sub → HabitsApp

Free habit cap: REMOVED in fc2400b42
Tier progression: full for all (post-paywall)

Proposed (soft paywall)

AuthGate state machine:
  unsigned → WelcomeScreen
  signed-in + onboarding incomplete → OnboardingFlowV2
  signed-in + onboarding done → HabitsApp
    (paywall shown ONCE during onboarding step 17,
     "Continue with free" dismisses to free tier)

Free habit cap: RESTORED — 3 habits max on free
Tier progression: capped at iron on free; gold/legendary = Pro
In-app prompts:
  - Try to add 4th habit → bottom sheet upsell
  - Reach iron tier → soft gold prompt
Implementation scope (estimated 4 commits):
  • Commit 1: Update PaywallStep (step 17) — add "Continue with 3 habits free" link, expand pricing copy. ~30 LOC. Add a callback prop to handle the dismiss path.
  • Commit 2: AuthGate gating logic — remove the hard paywall block, route signed-in onboarded users straight to HabitsApp regardless of subscription. The paywall is now reached only via onboarding step 17. Tier check moved to per-feature gates. ~50 LOC across AuthGate + maybe a small subscription helper.
  • Commit 3: Restore free habit cap — re-introduce FREE_HABIT_LIMIT = 3 constant, gate at habit-create + show in-app upsell sheet. Re-uses the bottom-sheet UI we already have for other modals. ~80 LOC.
  • Commit 4: Tier-cap on free tier — strength reaching 60 (iron threshold) for non-Pro users shows the gold prompt instead of upgrading the visual tier. Material renderer accepts an "isLocked" tier state. ~40 LOC.

Risk + rollback:
  • Each commit independently revertable. If conversion craters in week 1, revert commits 2 and 3, keep commit 1's improved copy.
  • Apple App Review: soft paywalls are explicitly preferred — lower rejection risk than current hard gate.
  • Free users who never convert: still positive LTV via referral and word-of-mouth (zero with hard paywall — they bounce).
