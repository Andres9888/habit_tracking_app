Why different animations?

Left (Transformation): The empty screen evolves into the habit home. First-habit celebration with confetti. The user isn't going anywhere; their world is coming to life.

Right (Navigation): The add-habit modal slides over the existing screen. The user takes a detour, then returns. Only the new row uses the shared fade-in-up stagger.

Shared DNA: Both use the same spring physics (damping: 18, stiffness: 150), the same 20px translateY, and the same 100ms stagger gap. Same rhythm, different choreography.
