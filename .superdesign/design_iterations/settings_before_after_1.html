Why these changes
  • Dead upsell → live row. The “Learn more →” link currently dead-ends. Backend already supports per-habit times (schema + scheduler exist). After: premium users get a real “3 habits use custom times → Manage” deep-link; free users get the same row wired to open the paywall.
  • Global time labeled. Adds “Default for all habits” so the two reminder rows read as a hierarchy, not duplicates.
  • Danger zone separated. Delete account was visually identical to Sign Out — one tap from irreversible. After: its own card, red “Danger zone” eyebrow, destructive-tinted icon + label.
  • Stats skeleton. Stats flash 0/0/0 before the query loads, reading as “new user.” After: shimmer placeholder until real values arrive.
