Privacy · Terms · v2.4.1 (42)
1 Move completion sound → Habits
Sound on check-off is habit feedback, not a push reminder. Sitting under Reminders forces users hunting for “sound” to open the wrong mental model. Code already comments this as a historical artifact.
2 Honest export subtitle
Today the row says “CSV or JSON” then immediately toasts “Export started…” with no format picker. Either ship a format sheet, or tell the truth about what you export. Prefer honest single-format copy until a picker exists.
3 Sort disclosure chevron
Sort expands inline on tap, but the row looks like a static value — no open/closed cue. Rotate the chevron (or swap value→chevron) so expansion matches Calendar look / navigation rows.
4 Align “Remind me at”
Nested time row has no icon tile, so its left edge sits flush and breaks the icon column rhythm. Add a small clock tile so the inset card matches every other interactive row.
5 Live value on streak toggle
Subtitle can carry the live time (“Every day at 8:00 PM” / “Off”) instead of static marketing copy — readable without expanding the inset.
Scope of this pass: IA + interaction + honest copy.
Support rows and visual system stay as-is (serif labels already ship).
Zero features cut — sound just moves; export still exports.
