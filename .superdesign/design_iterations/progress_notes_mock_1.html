How it would work

1. Chain (existing)

tracking — habitId + date + completed boolean → streaks & strength

2. Progress entry (new)

progressEntries — same habitId + date, plus signal, note, optional metrics

3. Habit-level anchor (existing)

habits.notes — static “why” blurb; why / WOOP stay on habit doc

// convex/schema.ts (sketch)

progressEntries: defineTable({
  habitId: v.id("habits"),
  userId: v.string(),
  date: v.string(), // YYYY-MM-DD
  signal: v.optional(
    v.union(
      v.literal("better"),
      v.literal("same"),
      v.literal("worse"),
    ),
  ),
  body: v.optional(v.string()),
  metrics: v.optional(v.array(
    v.object({ label: v.string(), value: v.number() }),
  )),
}).index("by_habit_and_date", ["habitId", "date"])
