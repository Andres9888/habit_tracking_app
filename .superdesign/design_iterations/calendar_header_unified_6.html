Purpose-Driven Audit

Does it change behavior?

Every element must solve a pain point or move the user closer to completing their habits. If it doesn't — cut it.

The test
Does this element solve a user pain point? ("How many left?", "Am I losing progress?", "What day?")
Does it change behavior? (Creates urgency, triggers loss aversion, answers a question)

If the answer to both is no — it's decoration. Cut it.
