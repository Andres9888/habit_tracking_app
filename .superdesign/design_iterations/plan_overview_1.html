Screen 1 · Welcome
Three fixes stacked

Social proof (review 04 H2) uses the existing SocialProofBadge component. Apple button (04 H3) renders with solid black fill + white Apple glyph so the label can't go invisible on any rendering surface. Tagline (04 M1) is replaced with a concrete promise — "One small thing, day after day" — not generic wellness-app boilerplate.

Screen 2 · Home empty
Teaches the metaphor in context

Ghost card + "PREVIEW" eyebrow do the work the auto-skipped onboarding carousel was supposed to do. WOOP and Vision re-enter here as secondary paths — users who want scaffolding before the first habit get a route to it; users who don't can tap the solid green CTA and move on.

Screen 3 · Create habit
Save reads as save

Save pill is filled primary[600] the moment the name field has content. Emoji grid uses explicit grid-template-columns: repeat(7, 1fr) — fixes the column-collapse regression on web (02 H2), also hardens the native rendering. Advanced stays collapsed by default with a single summary row instead of three sub-pickers.

Screen 4 · Populated home
Chain visualization scales

12-day chain shows as 12 discrete dots — small enough to fit the card, large enough to count. Today's dot uses the ring treatment already in the codebase. The 2-of-3 progress ring in the header gives a daily summary without a separate chart. Reorder affordance is called out in footer text instead of hidden in a long-press.

Screen 5 · Library
One palette, no free-range hex

Goal-card icon tiles pull from four existing token roles: primary[600] (movement), streak[600] (rest/gold), premium[500] (mind/purple), info[500] (learning/blue). Replaces 14 raw hexes in categoryMeta.ts. Featured CTA is filled white-on-dark (unambiguous), not a ghost pill. Grid chevrons are Lucide icons, not styled text arrows.

What's next
Three screens not drawn yet

Analytics — needs low-data variants (03 A2) before it's worth mocking. Character — the progression curve fix (03 C2, C3, C5) is the substance; the visual is less urgent. Habit detail — populated detail was unreachable in the review pass; would design it after a fixture pass with real data. I'd tackle these after the 5 screens above ship.

Rendering caveat. This is Chrome at desktop; on native iOS the fonts, shadow falloff, and ghost-card dashed border will differ slightly. Safe for intent review; validate final pixel values on-device once the expo-crypto iOS build failure is resolved. Files referenced live in src/theme/, src/components/, src/screens/, and src/features/habits/.
