Map visual stays. Below it: three benefit lines, each pairing a user-facing payoff (bold) with the underlying feature (faded). Each one answers a problem-screen question.
What changed from V1 original
  • Problem screen: Added "You're lost." as a burnt-orange diagnosis between the three questions and the consequence. Original kept its rhythm; new line gives the questions an emotional payoff before "so you quit."
  • Solution headline: Unchanged — "We give you the map."
  • Solution map: Same path bar, same tier markers (Copper / Iron Ridge / Gold Summit), same Day 1 marker. Removed the 20%-cell row from inside the map block — that idea is now elevated to its own benefit line below.
  • Solution sub-copy: "Per-habit difficulty. Named waypoints. Visible chain upgrade every 20%." → three benefit rows with payoff + feature.

Each benefit answers one problem-screen question
  • "How long? How hard?" → ⏱ Know how long, how hard. Science-backed length, per habit.
  • "How close am I?" → 📍 Know where you are. Know what to climb to. Named markers: Copper, Iron Ridge, Gold Summit.
  • (Implicit need: don't quit between milestones) → 🔗 Watch your chain transform. Every 20% of the way, a visible upgrade — proof, not numbers.

Why row 2 lands harder now
  • Two paired clauses: "Know where you are. Know what to climb to." — orientation first, then motivation. Same "Know X. Know Y." rhythm as row 1, so the three rows scan with shared shape.
  • "Climb to" carries energy that "what's next" doesn't — it implies an aspirational peak (Iron Ridge, Gold Summit), not just the next thing on a list.
  • Feature line names the markers — the map visual just above teaches the reader what Copper/Iron Ridge/Gold Summit mean. The line reinforces the visual instead of repeating it.

Why row 3 lands harder now
  • The benefit moved from "fast progress" (vague) to "watch your chain transform" (concrete sensory payoff). The user gets to see something happen — that's the actual win.
  • "Proof, not numbers" is the contrast — it tells the user what they've been getting from other apps (numbers ticking up) vs. what they get here (a chain that visibly changes).
  • No app-side change required. The chain already upgrades through tier levels every 20%; this copy just makes that benefit explicit.

Alternate phrasings if you want to A/B
  • Row 2 alt A: "Know where you are." alone (drop the second clause) — minimal, lets the named markers in the feature line carry the climb idea.
  • Row 2 alt B: "Always have a peak to chase." — pure motivation framing, drops orientation.
  • Row 3 alt A: "Five visible wins per habit, not one." Concrete number; works because 100% / 20% = 5 chain upgrades per habit. Stronger if you want to lean numerical.
  • Row 3 alt B: "Always one upgrade away." Pure motivation framing — what you're chasing, never how far you've come.

Still open
