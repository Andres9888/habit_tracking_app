7 surfaces · primitive consolidation
Empty states migrated to canonical primitive
◐ Layout subtle

7 empty-state components migrated to a single EmptyState primitive (with new compact size, iconBackplate, and actionSlot props). Underlying styling slightly changes per file — most are ≤8px padding/spacing differences. Watch for:

1 · Paused habits modal — open Settings → Paused. The "No paused habits ⏸️" empty state. Icon size + text alignment may be slightly different.
2 · Habit Rankings empty — analytics rankings tab when no habits yet. "No Habits to Rank Yet" with the list-ordered icon.
3 · Day Habits bottom sheet — tap a calendar day with no habits. The "No Habits Yet" clipboard icon empty state.
4 · Streak records empty — Habit Detail → Streak History accordion when no streaks exist. "No Streaks Yet" with the orange flame icon backplate.
5 · Archived habits modal — Settings → Archived. The "All habits are active 🌱" empty state with the tip card.
6 · Smart suggestions empty — inside Create Habit modal when no template suggestions. The 🎯 "Create your own unique habit!" box.
7 · Emoji picker empty — search for an emoji that doesn't match. The "No emojis found" search-icon state.
Today screen · habit cards · motion
HabitCard accent-bar bounce
◐ Minor motion shift

When a habit card mounts, its left-edge colored accent bar animates its width from 0. The bounce is now slightly bouncier — damping shifted from 12 to 10 via the springs.bouncy preset (stiffness + mass preserved).

Where to look: any moment a new habit card mounts (loading the Today screen, scrolling new ones into view if windowed, returning from background).

What you won't see different

Most of the 256-file diff is token references with identical rendered values. Examples that don't change a pixel:

  • 26 sites of borderRadius: 9999 → borderRadius.full — same number, renders identically
  • 188 sites of raw fontSize: N → typography.X.fontSize for exact-match values (10/13/14/17/20/22/34) — token resolves to the same number
  • 27 exact-value borderRadius: N sites → token references — same numbers
  • GoalWhyAnchor + GoalCoachLine hex values → colors.parchment.* + colors.tone.* — same colors, just named
  • Spring preset spreads in StrengthRing + DraggableHabit — explicit overrides preserve exact original behavior
