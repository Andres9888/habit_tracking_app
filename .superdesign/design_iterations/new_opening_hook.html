How they differ:
  • V1 — Direct: Three rapid-fire questions ("How long? How hard? How close?"). Most assertive opening. Solution screen is the densest — visual answers all three at once.
  • V2 — Honest-emotional: Metaphor-led. "A new habit is a new destination." Quieter, more reflective. Solution: "Now you can." Cleanest tonally with the rest of the app's voice.
  • V3 — Question-led: Single quoted question — "Where am I?" — your user's own voice. Pure-copy problem screen, no visual. Solution screen explicitly answers with a position pin: "📍 You're at Day 7."

What's the same across all three:
  • Welcome stays as "Hey."
  • Solution screens use the same Habit Map visual we already shipped
  • Anti-streak attack copy is gone — replaced by "you can't see, now you can" framing

My recommendation: V2 (Honest-emotional) for ChainDay's voice. Metaphor opens with warmth ("destination"), problem lands without attacking the user, solution closes with the same map visual that recurs throughout the rest of the flow. V1 is sharper but more interrogative — risks feeling like a sales pitch. V3 is poetic but the solution screen risks reading too feature-y for the opener.
