Issue 3 — Hardcoded #FFFFFF (~30 files)
White color bypasses colors.text.inverse token
The theme defines colors.text.inverse as '#FFFFFF' in light mode and '#111827' in dark mode. ~30 component files hardcode '#FFFFFF' instead, which would break if inverse text ever needs to adapt.
Pattern found across 30+ files
color='#ffffff'
ProgressRingFAB.tsx
→
colors.text.inverse
Same visual, maintainable token
Files affected: ProgressRingFAB, SocialSignInButton, QuickCompleteButton, SwipeableActionButton, StreakMilestoneCelebration, StreakChain, TemplateAddedToast, NameInputSection, EditHeader, HeroFooter, SettingsModal, NavigationButtons, and ~18 more.
Issue 4 — Icon Size Token Gaps
iconSizes tokens exist but most icons use raw numbers
The theme defines 6 icon size tokens (10, 16, 20, 24, 32, 48) but components frequently use hardcoded numbers including sizes 12, 14, 18, 28 that have no matching token.

Issue 5 — Hardcoded Border Radius (37 occurrences)
borderRadius: 12 used instead of borderRadius.button token
The theme defines borderRadius.button = 12 and borderRadius.card = 16, but 37 places hardcode the raw number. Values match today, but won't propagate if the design system changes.
