① Mode chip — Balanced · 63d

Surfaces the algorithm choice (auto-picked from template duration, per commit 98f4ae19d). Users see "this is the 63-day curve, calibrated to Lally 2010" — the science becomes a feature, not a hidden constant.

② Bigger ring (104px) with tier color

Ring stroke is the tier color (amber for Developing) — semantic, never clashes with the user's habit color. Habit color stays as a subtle dashed inner accent for personalization. Fixes the cyan-vs-amber clash visible today.

③ Honest microcopy ("First dip in 2 weeks")

Replaces the duplicated "+25% vs last month" with the most-truthful-and-relevant single line. Surfaces the -4% last-week decline that today's hero hides. The headline stops cheerleading and starts narrating.

④ Screen-reader fix

Ring's accessibilityLabel now reads the actual tier ("35%, Developing"), not the hardcoded "Strong" bug in ProgressRing.tsx:52. One-line code change; massive correctness win.

⑤ Chart range scoped honestly

Toggle relabeled "Chart range" and moved over the chart. Ring + deltas always reflect current strength — no longer pretending the toggle scopes everything. Cheaper than re-scoping all metrics, more honest UI.

⑥ Y-axis + 85% target line

Chart is now readable: 0 / 50 / 85 / 100 grid, dashed "habit-formed" line at 85% (the threshold the algorithm targets). Users see how far they are from the goal, not just a decorative wiggle.

⑦ Milestone dot on chart

Small flag at "25% · Apr 22" celebrates the day they crossed a tier. Adds a sense of journey to a static curve. Per the design-intent doc: bias toward what keeps users coming back.

⑧ "Why this number ↗"

Tappable hint opens a sheet with the 7-day breakdown (✅ ✅ ⬜ ✅ ✅ ✅ ⬜), the per-completion delta, and a plain-English mode explanation. The math becomes inspectable, builds trust.
