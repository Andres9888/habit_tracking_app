Findings & Recommendations

📍

1. Sort Button Position

MODERATE

Sort control is in the header row, far from the habit list it controls. Creates cognitive distance.

Recommendation:

Move sort to section header directly above habit list, or integrate into momentum meter (see previous mocks).

🎨

2. Color Palette Inconsistency

CRITICAL

Multiple color systems in use across components:

HabitsEmptyState

Slate palette

DraggableHabit

Stone palette

Recommendation:

Standardize on Stone palette throughout (warmer, matches beige bg). Update HabitsEmptyState colors.

📊

3. Strength Bar Inconsistency

MINOR

Some habits show strength bar, others show plain divider. Setting exists but visual treatment differs.

Recommendation:

When strength is hidden, use consistent divider style matching strength bar height (1.5px vs 1px currently).

➖

4. Divider Opacity Mismatch

CRITICAL

Dividers use different opacity values:

  • Habit card divider: rgba(120, 113, 108, 0.08)
  • Border color: #f5f5f4 (stone-100)
  • Some use Tailwind classes, others inline styles

Recommendation:

Create shared divider component or constant. Use stone-100 (#f5f5f4) consistently.

✅

5. Completed Habit Treatment

MINOR

Completed habits use opacity-70 + strikethrough. Could be more celebratory.

Recommendation:

Consider subtle green tint on completed cards instead of dimming. Keeps positive reinforcement.

Additional Findings

✨

What's Working Well

  • Card border radius — Consistent 24px (rounded-3xl) on habit cards
  • Icon sizing — 44px (11×4) icon containers follow Apple HIG tap targets
  • Haptic feedback — Consistent use of haptics for interactions
  • Animation springs — Using reanimated springs with consistent damping/stiffness
  • Warm background — #f8f5f1 beige creates friendly, approachable feel
⚡

Quick Wins (Low Effort, High Impact)

  1. Replace slate colors in EmptyState with stone palette
  2. Unify divider opacity to stone-100
  3. Add subtle green tint to completed habit cards
  4. Move sort button into momentum meter (single line change)
