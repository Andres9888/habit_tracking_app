Item 11: Dynamic Popularity

Before

Static popularityScore hardcoded in seed data (76-98). Never changes. Rankings are arbitrary.

After

Daily cron computes scores from real templateUsage import counts. Rankings reflect actual user behavior.

Visual Note

The rank numbers, import counts, and progress bars shown here are illustrative. The actual UI won't change much - the existing trending carousel and sort-by-popular will just use real data instead of static scores. The visual enhancement is optional.

Formula

score = min(100, max(baseline, importCount * scale))

Baseline preserves seed scores until real data accumulates.
