✕ Problem with the dropdown
A big green CUSTOMIZE button competes with the primary Create Habit CTA and implies customizing is required. The options are hidden one tap away, and the labels ("Strength Curve", "Growth Icons") are jargon.
✓ Why the open list wins
Options are visible & self-explanatory (plain titles + one-line "what it does"), an Optional pill + reassurance line remove pressure, and Create Habit is the only primary button — a cleaner funnel. Reuses the existing row component, so it ships fast.
