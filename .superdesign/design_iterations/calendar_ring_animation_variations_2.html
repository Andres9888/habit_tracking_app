Science & UX
Fitts's Law: The pill creates a large, bounded tap target. The subtle green border + background shift uses pre-attentive processing — the eye detects the enclosed shape before consciously reading the text. iOS Precedent: Calendar.app uses a pill for its date selector. Users are pre-trained to tap pill-shaped date elements. Hover state confirms interactivity.

Science & UX
Web convention: Dashed underline universally signals "this text has more info / is interactive" (tooltips, abbreviations). It's subtler than a pill but still visually distinct from static text. Nielsen Norman: Underlines are the most recognized interactive text affordance after color. The dashed variant says "tap to expand" rather than "this is a link."

Icon superiority effect: Calendar icons are universally recognized (~99% comprehension rate per NN/g icon studies). The icon tells users "there's a calendar here" before they even read the text. The subtle pulse animation on first load draws attention once, then stops — habituation-aware (doesn't keep animating). Replaces the green dot with a functional signifier.

Science & UX
Motion salience (Yantis): A subtle bounce on the chevron is the lightest-weight way to say "I'm interactive." The animation runs 3 times on first load then stops — progressive disclosure without being annoying. Minimal footprint: No visual change to the layout. The chevron was already there; we just make it whisper "tap me" once. Combine with D1 for maximum effect: pill shape (static affordance) + bouncing chevron (dynamic affordance).
