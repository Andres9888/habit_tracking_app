A- — Import Friction
The 1-tap "Add" button on trending cards is the strongest UX win. Goes from 10-field form → single tap. Duplicate detection prevents double imports gracefully.
B — Information Hierarchy
Smart curated layout: Featured hero → Popular carousel → Packs → Categories. Time-aware featured collection rotates by morning/afternoon/evening. Users see the best content first.
B- — Quick Filter Chips
Only shows 7 of 14 categories. Missing: Breathing, Creativity, Recovery, Social, Longevity, Huberman. Users interested in those must scroll past everything to the category grid.
D — "See All" Dead End
Tapping "See all" on Trending dumps the user into a flat FlatList of 200+ templates with no search, no sort, no filter. The paradox of choice returns.
C — Category Grid
Initially shows only 6 of 14 categories behind a "Show all" button. Categories like Recovery and Social are hidden by default. Users must know to expand.

Strength — Time-Aware Featured
The hero card rotates by time of day (morning green, afternoon blue, evening purple, weekend magenta). Contextually relevant content increases engagement.
C — Science Badge Everywhere
Every template shows the 🔬 science badge because scientificReference is required in the schema. The "Research only" toggle is a no-op — it filters nothing out.
C — Premium Packs No Gate
Pack cards show "Import Pack" with no premium badge or lock icon. Free users discover the limit only after tapping and having the import partially fail. Should show premium status upfront.
D — Bottom Bar Discovery
Templates are accessed via this tiny 📖 icon. No label. New users see a notification dot but have no idea what it means. The #1 reason cold-start isn't solved.
B — List Card Design
Compact cards with icon + title + 2-line description + action buttons. "Add" and "Preview" are clearly separated. Match reason shown during search. Good information density.
A — Match Feedback
When searching, each card shows why it matched ("Match: title", "Match: research summary"). Reduces confusion about irrelevant-looking results.
C- — Post-Import Gap
After tapping "Add", the habit is created with only name, icon, color, frequency. The rich fields the app supports (cues, identity, goals, WOOP) are all empty. Template habits ≈ manual habits.

Strength — Sort + Filter
Category view has sort (Popular/A-Z) and research toggle. Significantly better than the flat "See All" view which has neither.
D+ — "Science" Badge on Everything
All 3 results show the green "Science" pill. Since scientificReference is required on every template, this badge appears on 100% of templates. It communicates nothing.
Missing — No Difficulty/Time Info
Cards show frequency (Daily) and category but no time commitment. Users can't tell if "Gratitude Journal" is 2 min or 20 min. The HeroSection hardcodes "5-10 min" for everything.
C- — What Gets Imported
Tapping "Add" creates a habit with: name, icon, color, frequency, and a notes field stuffing description + scientific reference together. No cues, no identity statement, no goals. The psychology engine goes unused.
CRITICAL — Onboarding Skipped
The 3-screen onboarding carousel (which mentions "200+ Templates" on page 3) is auto-completed for all new users in useOnboardingStatus.ts:25-26. New users never see it.
CRITICAL — Empty State ≠ Templates
The quick-start chips (Meditate, Read, Exercise, Drink Water) are hardcoded constants using QuickStartTemplate type — not connected to the real template library. They create bare habits, not template imports.
CRITICAL — No Path to Templates
A new user with 0 habits sees this empty state. The only path to templates is the tiny 📖 icon in the bottom bar. There is no "Browse Templates" CTA, no onboarding nudge, no contextual prompt.

This is what a new user sees
After sign-up, onboarding auto-completes. The user lands here with 0 habits. The quick-start chips are nice but create bare-bones habits with no science backing, no cues, no identity framing.
Disconnected Systems
These chips use a QuickStartTemplate type (name + emoji + duration). The real template library has 200+ templates with scientific references, categories, popularity scores, tips. The two systems don't talk to each other.
The Biggest Gap
The templates page was built to solve cold-start. But the cold-start moment (this screen) has no connection to it. The entire feature is hidden behind an unlabeled icon that looks like a settings page. The solution exists but the problem never sees it.

3 Highest-Leverage Fixes

FIX 1 — DISCOVERY
Surface templates at the moment of need
Make the empty-state CTA open templates (not create-habit). Or show a curated 6-8 template picker as the first post-signup screen. The feature exists — it just needs a front door.
FIX 2 — DEPTH
Enrich template schema with cues + identity
Add cueAfterBehavior, identity, cueTime to template data. Pass them through in importTemplate. Template habits should be genuinely richer than manual ones.
FIX 3 — CREDIBILITY
Fix the research filter + science badges
Change "Research only" to filter by scientificLink (verifiable URLs), not the always-present scientificReference. Show the science badge only when there's a real link.
