2a vs 1a
Rows rest closed. Every row is one 60px line: tile, title, one-line hint, value chip, chevron. Tap a row to open its picker in place (Streak goal shown open). The screen drops from ~4 pickers on screen to one.
Set vs. unset reads at a glance. Filled chip = chosen ("7 days", "Average", "Plants"); outlined chip = nothing yet ("Add"). Same row hue either way.
Reminder joins the panel. "Daily reminder" becomes row one with the same tile + title anatomy instead of a separate card with its own header treatment.
Whole screen on one grid. Icon and Color labels move left in the panel's caps style, with the action ("Browse all") on the right — same line the panel header uses. Icons sit on a true 5-col grid with a "+" tile; colors compress to a single row so the screen shortens without losing options.
No collapse button at all. With rows at rest the panel is already short, so the header no longer needs a Hide/Customize toggle. "Optional" on the right tells the user they can skip it.

What changed in 1a
One hue per row, one tint level. Why = amber, Streak = gold, Curve = green, Growth = violet (the app's per-mode violet). All four tints sit at the same lightness so they read as a set, not four separate palettes.
Value chip echoes its row. Each row's chip uses the same tint + ink as its icon tile, borderless. Green stays reserved for the selected option inside the pickers.
One chip component. Streak, curve and growth stages all use the same 66px chip: stone at rest, primary-100 + primary-500 ring when selected. The amber "Off" chip and the floating START badge are gone; recommended options carry a small green dot.
Strength Curve matches its siblings. Same head anatomy and an inline 3-chip picker. Copy now asks the question the user can answer ("How hard is this habit?"), chips lead with the difficulty word and demote the % to a micro label. Each chip keeps its mode icon in the app's per-mode color (sprout / trend / mountain) while surfaces stay stone; the deep-dive sits behind "See the difference", same pattern as "Themes".
Quieter toggle. The full-width green "Hide options" pill becomes a header row with a chevron; summary chips only show when collapsed.
Growth stages use the same chip. Each stage is now a 66px emoji + label chip like Streak and Curve, so all three pickers read as one component. "YOURS" marks the stage your habit icon fills in; NEW / STRONG live inside the chips.
Why field matches the panel. Stone fill, 14px radius, no serif; the counter sits inside the field. Placeholder "I want to feel…" starts the sentence for them.
Copy pass. Every row: one plain sentence, then a green-dot helper line only where it changes the decision. Streak chips say what the number is (DAYS) instead of tier names; "Off" becomes "— NONE".
