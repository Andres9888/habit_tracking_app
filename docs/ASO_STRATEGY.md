## 5. Review Solicitation Strategy

### When to Ask for Reviews

**Never ask:**
- During onboarding (too early)
- After a single day (no loyalty yet)
- After a broken streak (user is frustrated)
- More than once per 90 days (Apple policy)

**Best times to ask:**
1. **After 7-day milestone**
   - User has proven commitment
   - First "aha moment" of seeing week-long chain
   - Prompt: "🎉 Congrats on your 7-day streak! Enjoying Chain Day? Leave us a review!"

2. **After 30-day milestone**
   - Strong habit formed
   - High emotional investment
   - Prompt: "🔥 30 days! You're building serious momentum. Mind leaving a review?"

3. **After perfect week (all habits)**
   - Peak motivation/satisfaction
   - Prompt: "Amazing! You completed all habits this week. Help others discover Chain Day?"

4. **After viewing statistics**
   - User is reflecting on progress
   - Already in analytical mindset
   - Prompt: "Love tracking your progress? Share your experience with a quick review!"

### Implementation

Use Apple's `SKStoreReviewController` (iOS) or Google Play In-App Review API (Android):

```typescript
import * as StoreReview from 'expo-store-review';

async function requestReview() {
  if (await StoreReview.hasAction()) {
    await StoreReview.requestReview();
  }
}
```

### Review Gating Logic

```typescript
const shouldRequestReview = () => {
  const lastReviewRequest = getLastReviewRequestDate();
  const daysSinceLastRequest = getDaysSince(lastReviewRequest);
  
  // Never ask more than once per 90 days
  if (daysSinceLastRequest < 90) return false;
  
  // Check milestone conditions
  const hasSevenDayStreak = hasActiveStreakOfDays(7);
  const hasThirtyDayStreak = hasActiveStreakOfDays(30);
  const hadPerfectWeek = completedAllHabitsThisWeek();
  
  return hasSevenDayStreak || hasThirtyDayStreak || hadPerfectWeek;
};
```

### Handling Negative Feedback

Before triggering OS review dialog, use a pre-filter:

1. **Sentiment check:** "How's your experience with Chain Day?"
   - 😞 Not great → Direct to support email
   - 😐 It's okay → Collect feedback in-app
   - 😊 I love it! → Trigger review dialog

2. **Support first:** If user rates <4 stars internally, don't prompt for public review. Instead:
   - "Sorry to hear that. Want to tell us what could be better?"
   - Direct to in-app feedback form
   - Offer to help via email

This protects public rating while collecting actionable feedback.
