# WelcomeScreen (React Native)

Landing screen that leads to sign up or sign in.

## State

- `mode: "welcome" | "signin" | "signup"`

## Usage

Rendered as part of the auth flow; toggles between `SignInScreen` and `SignUpScreen`.

## Key UI

- Hero title and tagline
- Buttons: "GET STARTED" (signup) and "SIGN IN" (signin)
