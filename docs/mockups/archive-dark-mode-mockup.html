✨ What Was Fixed

🎨 Dynamic Theme Colors

All components now use useThemeColors() to adapt to dark/light mode automatically. No more hardcoded colors.

📱 Habit Cards

Card backgrounds, borders, and text colors now properly switch between light (#ffffff) and dark (#1f2937) themes.

🏷️ Badge Colors

Strength, streak, and completion badges use dark-mode-optimized color variants for proper contrast.

🔘 Action Buttons

Restore and delete buttons adapt their border and text colors to maintain visibility in dark mode.

📊 Stats Summary Bar

Background shifts from stone-50 (light) to gray-800 (dark), with adjusted text contrast.

📝 Typography

All text elements use theme-aware colors from the design system (text.primary, text.secondary).
