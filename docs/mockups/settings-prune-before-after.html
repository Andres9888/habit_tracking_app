Version 2.4.1 (1) · What's New · Terms · Privacy
1 Cut "Default growth icons"
The handoff README lists the growth-icons row under "Removed from the old Settings (intentional) — do not re-add". It survived only because it wasn't in the removal set you approved. The emoji preset feature stays reachable when editing a habit, which is where you actually choose one. Kills a row plus its always-mounted picker tray — and a Convex query on every Settings open.
2 Collapse the Sort order picker
Today the two-tier picker (family segments + direction segments) renders expanded at all times — the single heaviest block on the page, ~120pt for a setting most people touch once. Collapsing it behind the value row matches how Calendar look and Theme already behave. Same capability, one tap away.
3 Pull the App lock stub
The toggle persists a flag but nothing enforces it — no biometric prompt, no gate on open. A user who flips it on believes the app is locked when it isn't. That's worse than the row not existing. Schema and plumbing stay in place, so restoring it is one component once expo-local-authentication lands.
4 "Streak Reminders" → "Daily reminder"
Spec 4a's name, and the subtitle carries the live value ("Every day at 8:00 PM" / "Off") instead of static marketing copy. You can read your setting without opening it — the same value-hint pattern every other row on the page uses.
5 Support: 4 rows → 2
Rate and Share are the same intent ("I like this, spread it") and both end at a system sheet. What's New is a changelog, not a setting — it belongs on the footer line with Version. Weakest item here: if these rows actually drive installs for you, drop this one and keep the other four.
Net: 17 rows → 11. Roughly a third less scroll.
Two removals are the design brief's own instructions; one is a correctness fix; two are polish.
Zero features lost — every capability stays reachable, just not all shouting at once.
