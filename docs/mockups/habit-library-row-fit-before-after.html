03

Why this is the row, not a new screen

Locked grilling

Name the problem → pick the habit. Preview is optional, so the row must answer “will this fix that problem?” before anyone opens Details.

Job
The user can name the problem, not the habit. Success is adding one matching habit from this catalog — not browsing a new surface.
Row = preview
Add on the row may skip Details. If fit is only in the preview, people who never open it cannot tell whether the habit is for them.
Pain on the card
Section headers vanish in search and when a chip shortlists a category. Category/pain has to live on the card or the problem has no name.
Search as pain
“Search habits…” trains title lookup. Search has to hit problem language (and copy like “can’t sleep”), not only habit names.
