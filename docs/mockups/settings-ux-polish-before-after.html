Reordered sections to follow a logical flow: Account → Preferences → Premium → Data → App → About. Account info is now at the top for easy access.

Added "Manage Subscription" link for premium users to access App Store subscription settings directly.

Renamed "Habit Management" to "Data" and "Completion Sounds" to "Sounds" for consistency and brevity.

Created dedicated "About" section for version info instead of floating text at the bottom.

Premium status and subscription management are now grouped together in a dedicated "Premium" section for better discoverability.
