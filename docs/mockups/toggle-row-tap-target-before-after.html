Implementation sketch

SettingsRow.tsx:70 currently short-circuits: if (type === 'toggle' || (type === 'info' && !onPress)) return content;. Change: only the non-interactive info case returns bare content; toggle rows get the same AnimatedPressable wrap as navigation rows, pressing calls handleToggle(!value).

// SettingsRow.tsx — after
if (type === 'info' && !onPress) return content;

const isToggle = type === 'toggle';
return (
  <AnimatedPressable
    accessibilityRole={isToggle ? 'switch' : 'button'}
    accessibilityState={isToggle ? { checked: !!value } : pressableState}
    onPress={isToggle ? () => handleToggle(!value) : handleNavPress}
    ...
  >
    {content}
  </AnimatedPressable>
);

A11y: row becomes the single switch element (role switch, state checked); mark the inner AnimatedToggle accessible={false} so VoiceOver doesn't announce it twice. Net a11y win — one large focusable target instead of a tiny one.

Keep: existing pulse animation + haptic in SettingsRow.hooks.ts — trigger from row press, unchanged when the switch itself is dragged. Repo gotcha honored: plain style arrays on Pressable, no function-form styles.
