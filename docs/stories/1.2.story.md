# Story 1.2: Implement Compact Mode for Habit Cards

**Status:** Approved
**Epic:** 1 - Core User Experience
**Story ID:** 1.2
**Created:** 2025-10-10

---

## User Story

**As a** user with many habits,
**I want** a compact mode option that reduces vertical spacing in habit cards,
**so that** I can see more habits on screen at once without excessive scrolling.

---

## Acceptance Criteria

### AC1: Compact Mode Toggle
- [ ] Settings menu includes a "Compact Mode" toggle option
- [ ] Toggle persists across app sessions (saved to device storage)
- [ ] Toggle state loads on app startup
- [ ] Toggle immediately updates UI when changed

### AC2: Compact Habit Card Layout
- [ ] In compact mode, habit card vertical padding reduces from 20px to 12px
- [ ] Gap between habit cards reduces from 16px to 8px
- [ ] Habit name font size reduces from 18px to 16px
- [ ] Chain visualization circles reduce from 40px to 32px diameter
- [ ] Streak label font size reduces from 12px to 10px
- [ ] Emoji size reduces from 24px to 20px

### AC3: Default Mode Preserved
- [ ] When compact mode is OFF, all original spacing from Story 1.1 is maintained
- [ ] 20px card padding (top/bottom)
- [ ] 16px gap between cards
- [ ] Original font sizes and component dimensions

### AC4: Smooth Transitions
- [ ] Layout changes animate smoothly when toggling compact mode
- [ ] No jarring jumps or layout shifts
- [ ] Animation duration: 200-300ms

### AC5: Responsive Design
- [ ] Compact mode works correctly on iOS, Android, and Web
- [ ] Layout remains readable and usable in compact mode
- [ ] Touch targets remain accessible (minimum 32px for interactive elements)

**Storage Key:** `habitTrackerSettings.compactMode`

**Storage Implementation:**
- Use AsyncStorage (React Native) or localStorage (Web)
- Store as boolean value
- Load on app initialization
- Update on toggle change

**State Flow:**
```
SettingsModal (toggle)
  → Update AsyncStorage
  → Update App.tsx state
  → Pass to DraggableHabit
  → Pass to HabitChainVisualizer
```

## Implementation Notes

### Recommended Implementation Order:
1. Create storage utility (Task 1)
2. Update SettingsModal with toggle (Task 2)
3. Wire state management in App.tsx (Task 3)
4. Update DraggableHabit styling (Task 4)
5. Update HabitChainVisualizer sizing (Task 5)
6. Adjust container spacing (Task 6)
7. Add smooth transitions (Task 7)
8. Test across all platforms (Task 8)

### Potential Challenges:
- **Animation performance**: Multiple habit cards animating simultaneously may cause jank
  - Solution: Use LayoutAnimation (React Native) or CSS transitions for smooth performance
- **Storage inconsistency**: AsyncStorage (mobile) vs localStorage (web) have different APIs
  - Solution: Create abstraction layer in storage utility
- **Touch target accessibility**: Compact circles (32px) are minimum size
  - Solution: Ensure no elements go below 32px, or add larger touch area with hitSlop
- **Text readability**: Smaller font sizes may be harder to read
  - Solution: Test with real users, consider minimum font size of 14px

### Dependencies:
- `@react-native-async-storage/async-storage` (React Native storage)
- React Native LayoutAnimation (built-in) or `react-native-reanimated`
- Existing components from Story 1.1: DraggableHabit, HabitChainVisualizer, SettingsModal

### Design Considerations:
- Maintain visual hierarchy even in compact mode
- Ensure sufficient contrast and readability
- Keep interactive elements easily tappable (≥32px)
- Consider adding "density" slider instead of binary toggle (future enhancement)
