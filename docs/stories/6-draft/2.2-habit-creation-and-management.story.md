# Story 2.2: Habit Creation and Management

**Status:** Draft
**Epic:** 2 - Core Habit Management
**Story ID:** 2.2
**Created:** 2025-10-12

---

## User Story

**As a** user,
**I want** comprehensive tools to create, edit, organize, and manage my habits,
**so that** I can maintain a personalized habit tracking system that adapts to my changing needs and preferences.

---

## Acceptance Criteria

### AC1: Enhanced Habit Creation Flow

- [ ] Quick-add habit creation with just a name (current functionality preserved)
- [ ] Advanced habit creation modal with comprehensive options
- [ ] Habit categories (Health, Fitness, Productivity, Learning, Personal, etc.)
- [ ] Custom emoji/icon selection for each habit
- [ ] Target frequency settings (Daily, Weekly, Custom days)
- [ ] Time-based scheduling preferences
- [ ] Initial notes and goal descriptions

### AC2: Habit Organization and Management

- [ ] Drag-and-drop reordering of habits in main list
- [ ] Habit categories with color coding
- [ ] Search and filter habits by category or name
- [ ] Archive completed or inactive habits (with restoration option)
- [ ] Bulk actions (archive multiple habits, change category)
- [ ] Favorite habits for quick access

### AC3: Detailed Habit Configuration

- [ ] Edit existing habits with full configuration options
- [ ] Set custom difficulty levels (Easy, Medium, Hard)
- [ ] Define completion criteria and success metrics
- [ ] Set target streak goals
- [ ] Configure reminder schedules per habit
- [ ] Add tags for better organization and search

### AC4: Habit Analytics and Settings

- [ ] Per-habit settings page with detailed configuration
- [ ] Habit history view with completion timeline
- [ ] Performance metrics and insights per habit
- [ ] Duplicate habit functionality for quick setup
- [ ] Export/import habit configurations
- [ ] Reset habit data option

### AC5: Mobile-Optimized Interface

- [ ] Touch-friendly habit creation interface
- [ ] Swipe actions for quick habit management
- [ ] Long-press context menus for habit options
- [ ] Modal-based editing with proper keyboard handling
- [ ] Responsive design for all screen sizes
- [ ] Accessibility features for habit management

## Dev Notes

### Technical Context

**Current Implementation (src/App.tsx, convex/habits.ts):**

- Basic habit creation with name only
- Simple `createHabit` mutation
- Habit ordering partially implemented
- No categorization or advanced features

**Convex Schema Enhancement Needed:**

```typescript
// Enhanced habits table fields needed:
- category: v.string() // Health, Fitness, etc.
- icon: v.string() // emoji or icon identifier
- frequency: v.string() // daily, weekly, custom
- difficulty: v.string() // easy, medium, hard
- targetStreak: v.number() // streak goal
- reminderTime: v.string() // HH:MM format
- tags: v.array(v.string())
- isFavorite: v.boolean()
- color: v.string() // hex color code
```

### Component Structure

**New Components Needed:**

1. **`HabitCreatorModal.tsx`** - Comprehensive habit creation form
2. **`HabitEditorModal.tsx`** - Edit existing habits
3. **`CategorySelector.tsx`** - Category selection with colors
4. **`IconPicker.tsx`** - Emoji/icon selection interface
5. **`FrequencySelector.tsx`** - Custom frequency scheduling
6. **`HabitSearchBar.tsx`** - Search and filter functionality
7. **`HabitSettings.tsx`** - Per-habit detailed settings
8. **`BulkActionsBar.tsx`** - Multi-select operations

**Enhanced Existing Components:**

1. **`App.tsx`** - Integrate advanced habit management
2. **`DraggableHabit.tsx`** - Add swipe actions, context menus
3. **`SettingsModal.tsx`** - Add habit management settings

### Feature Implementation Details

**Habit Categories:**

- Predefined categories: Health, Fitness, Productivity, Learning, Mindfulness, Social, Creative, Financial
- Custom category creation
- Color coding per category
- Category-based filtering

**Icon/Emoji System:**

- Native emoji picker integration
- Custom icon set fallback
- Recently used emojis
- Search functionality for icons

**Frequency Configuration:**

- Daily (default)
- Weekly (select specific days)
- Custom interval (every X days)
- Flexible scheduling with time preferences

**Archive System:**

- Soft delete with `archived: true` flag
- Archived habits view with restoration
- Bulk archive functionality
- Archive retention period settings

### Data Flow and API

**New Convex Functions:**

```typescript
// Enhanced habit mutations
- updateHabit: update existing habit with full config
- archiveHabit: soft delete habit
- restoreHabit: restore archived habit
- duplicateHabit: create copy of existing habit
- reorderHabits: persist habit order
- bulkArchiveHabits: archive multiple habits

// Enhanced queries
- getHabitsByCategory: filtered habits
- getArchivedHabits: archived habits list
- getHabitAnalytics: per-habit statistics
- searchHabits: text search functionality
```

### UI/UX Considerations

**Mobile-First Design:**

- Bottom sheet modals for habit creation/editing
- Touch targets minimum 44px
- Swipe gestures for quick actions
- Pull-to-refresh for habit list
- Loading states and skeletons

**Accessibility:**

- Screen reader support for all habit management actions
- High contrast mode support
- Voice control compatibility
- Keyboard navigation support

**Performance Optimizations:**

- Lazy loading for archived habits
- Debounced search implementation
- Efficient list rendering with React.memo
- Optimistic updates for habit actions
