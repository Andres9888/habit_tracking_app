# Story 2.5: Habit Streaks and Gamification

**Status:** Draft
**Epic:** 2 - User Motivation and Engagement
**Story ID:** 2.5
**Created:** 2025-10-12

## User Story

**As a** user,
**I want** engaging gamification elements and comprehensive streak tracking that make habit building feel rewarding and fun,
**so that** I stay motivated to maintain my habits long-term and celebrate my progress in a meaningful way.

- No gamification elements

**Enhanced Data Model Needed:**

```typescript
// New gamification tables in Convex schema:

achievements: defineTable({
  userId: v.id("users"),
  habitId: v.optional(v.id("habits")),
  type: v.string(), // streak, completion, special
  name: v.string(),
  description: v.string(),
  icon: v.string(),
  points: v.number(),
  earnedAt: v.number(),
  isDisplayed: v.boolean()
}).index("by_user", ["userId"])

userStats: defineTable({
  userId: v.id("users"),
  totalPoints: v.number(),
  currentLevel: v.number(),
  experiencePoints: v.number(),
  totalCompletions: v.number(),
  longestStreak: v.number(),
  currentStreakDays: v.number(),
  badgesEarned: v.number(),
  joinedAt: v.number()
})

streaks: defineTable({
  userId: v.id("users"),
  habitId: v.optional(v.id("habits")),
  type: v.string(), // daily, weekly, custom
  currentLength: v.number(),
  longestLength: v.number(),
  startDate: v.number(),
  lastCompletionDate: v.number(),
  isActive: v.boolean(),
  frozenDays: v.number()
})

challenges: defineTable({
  name: v.string(),
  description: v.string(),
  type: v.string(), // daily, weekly, event
  requirements: v.any(), // completion criteria
  points: v.number(),
  startDate: v.number(),
  endDate: v.number(),
  participants: v.array(v.id("users"))
})
```

### Gamification Mechanics

**Streak System Design:**

- Current streak: consecutive days completed
- Best streak: longest streak achieved
- Streak freeze: protect streak for missed days
- Recovery challenges: regain broken streaks
- Multiplier bonuses: consistency rewards

**Achievement Categories:**

- **Streak Achievements**: 7, 30, 100, 365 day milestones
- **Completion Achievements**: 100, 500, 1000 total completions
- **Consistency Achievements**: weekly/monthly perfect records
- **Special Achievements**: unique habits, challenges, events
- **Habit-Specific Badges**: per-habit milestones

**Points Economy:**

- Base points per completion: 10 points
- Streak multiplier: 1.5x for 7+ days, 2x for 30+ days
- Challenge bonuses: 50-200 points
- Achievement rewards: 100-1000 points
- Level progression: 1000 points per level
