# Story 2.7: Habit Stats and Notes Screen

**Status:** Draft
**Epic:** 2 - User Engagement & Insights
**Story ID:** 2.7
**Created:** 2025-10-15

---

## User Story

**As a** habit tracker,
**I want** a combined Stats & Notes screen to review performance trends and jot contextual notes,
**so that** I can understand my progress and capture insights that explain patterns in my habits.

---

## Acceptance Criteria

### AC1: Access and Navigation
- [ ] A "Stats & Notes" entry is available from the main header (icon next to Settings)
- [ ] Tapping opens a full-screen view with two tabs: "Stats" and "Notes"
- [ ] The view provides a close button with accessible label and keyboard support

### AC2: Stats Overview (All Habits)
- [ ] Shows today’s completion (X/Y), weekly completion % (last 7 days), longest streak, and current active habits
- [ ] Metrics update in real time when habits are toggled
- [ ] Consistent color scheme (success green #48bb78, neutral gray #dde3ed)

### AC3: Per‑Habit Stats
- [ ] Filter by habit to view its completion trend (last 30 days) and current/longest streak
- [ ] Includes bar chart (weekly) and line chart (30‑day trend)
- [ ] Chart tooltips or value callouts are accessible and readable

### AC4: Notes CRUD
- [ ] Users can add, edit, and delete notes
- [ ] Each note links to a date and optionally a habit
- [ ] Note body max 1,000 chars, shows createdAt/updatedAt timestamps
- [ ] Persisted and restored across sessions

### AC5: Notes Browsing and Search
- [ ] Notes list groups by date with newest first
- [ ] Filter by habit and free‑text search
- [ ] Editing uses a dedicated form with validation and accessible labels

### AC6: Error States and Offline
- [ ] Network errors show friendly messages and retry actions
- [ ] Draft note changes are not lost on transient failures
- [ ] Loading and empty states are clearly indicated

### AC7: Accessibility and Responsiveness
- [ ] Works on iOS, Android, and Web; layout adapts to small and large screens
- [ ] All interactive targets ≥32px, with proper roles and aria‑labels
- [ ] Tabs are keyboard navigable and screen‑reader friendly

### AC8: Performance
- [ ] Charts render within 300ms on typical datasets
- [ ] Scrolling the notes list is smooth with 60fps target
- [ ] No unbounded re‑renders on habit toggle

## Dev Notes

### Components
- `StatsNotesButton` (header entry)
- `StatsNotesScreen` (tab container)
- `StatsOverview`, `HabitStats` (charts + KPIs)
- `NotesList`, `NoteEditor` (CRUD with validation)

### Data and API
- Add `convex/notes.ts` with queries/mutations: `listNotes`, `searchNotes`, `createNote`, `updateNote`, `deleteNote`
- Suggested schema fields: `userId`, `habitId?`, `date (YYYY-MM-DD)`, `body`, `createdAt`, `updatedAt`

### Charts
- Use `react-native-chart-kit` or `victory-native` for RN; `victory` for Web
- Unified color palette aligned with existing green/gray scheme
