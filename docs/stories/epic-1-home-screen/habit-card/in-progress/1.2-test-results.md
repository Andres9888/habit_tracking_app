### 1. Conditional Haptic Feedback

```typescript
// Lines 165-168 in HabitCard.tsx
const hapticStyle =
  isCompleted === true
    ? Haptics.ImpactFeedbackStyle.Light // Unchecking (softer)
    : Haptics.ImpactFeedbackStyle.Medium; // Checking (stronger)
```

### 2. Optimal UX Flow

```typescript
// Haptic fires BEFORE mutation for immediate feedback
runOnJS(Haptics.impactAsync)(hapticStyle);

// Then mutation fires for database update
runOnJS(toggleCompletionMutation)({ habitId: id, date: today });
```

### 3. Query-Driven Haptic Decision

```typescript
// Query runs at component render to get current state
const isCompleted = useQuery(api.tracking.getCompletionStatus, {
  habitId: id,
  date: today,
});

// Haptic intensity determined by current state (not future state)
```
