## Goal

Build the main habit tracking interface where users view, complete, and manage their daily habits

## Screen Components

- Daily habit list with completion tracking
- Streak visual indicators (🔥 fire emoji + count)
- Milestone badges (⭐ 7-day, 🏆 30-day, 💎 100-day)
- Habit management UI (edit, archive, delete)
- Real-time streak updates

## Success Metrics

- Daily check-off takes <30 seconds for 5 habits
- 60fps smooth scrolling with 100+ habits
- Streak count updates instantly on completion
- Milestone celebrations trigger at 7/30/100 days
- 0 crashes during habit interactions
