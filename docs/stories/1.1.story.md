# Story 1.1: Update Home Page Screen to New Design

**Status:** Approved
**Epic:** 1 - Core User Experience
**Story ID:** 1.1
**Created:** 2025-10-10

---

## User Story

**As a** user,
**I want** an updated home page with a modern design featuring a date selector, visual habit chains, and streak information,
**so that** I can easily track my habits across multiple days and stay motivated by seeing my progress visually.

---

## Acceptance Criteria

### AC1: Date Selector Header
- [ ] Horizontal date selector displays 5 consecutive days (scrolling from 4 days ago to today)
- [ ] Each day shows: Month (OCT), Date number (1-5), Day of week (WED-SUN)
- [ ] Current day (today) is highlighted with darker text (#101727)
- [ ] Past days display in gray text (#a0aec0)
- [ ] Date selector updates dynamically based on current date

### AC2: Settings Icon
- [ ] Settings icon (gear/cog) appears in top-right corner of header
- [ ] Icon is aligned with "Habits" title vertically
- [ ] Tapping settings icon opens settings modal (existing SettingsModal component)

### AC3: Updated Habit Card Design
- [ ] Habit cards display with white background, 16px border radius, subtle shadow
- [ ] Each card shows: Emoji icon, Habit name, Chain visualization, Optional streak label
- [ ] Cards have 20px internal padding
- [ ] 16px gap between habit cards
- [ ] Emoji displays at 24px size on left side

### AC4: Chain Visualization
- [ ] 5 circular buttons (40px diameter) display horizontally for each habit
- [ ] Completed days show green circle (#48bb78) with white chain link icon
- [ ] Incomplete/missed days show light gray circle (#dde3ed) with no icon
- [ ] Connecting lines (2px height, green #48bb78) appear between consecutive completed days
- [ ] Chain link icon is white, centered in green circles

### AC5: Streak Display
- [ ] "STREAK • X DAYS" label appears below chain visualization
- [ ] Only displays for habits with active streak (consecutive completed days)
- [ ] Text is uppercase, 12px, semibold, gray color (#a0aec0)
- [ ] Letter spacing: 1.2px

### AC6: Visual Polish
- [ ] All spacing matches Figma spec (24px side margins, etc.)
- [ ] Typography matches design (Inter font family, weights, sizes)
- [ ] Colors exactly match Figma values
- [ ] Smooth transitions/animations for habit completion toggles
- [ ] Design works on iOS, Android, and Web
