# Security Policy

## Supported Versions

The latest release on the `main` branch receives security updates.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report privately via one of:

- GitHub's [private vulnerability reporting](https://github.com/Andres9888/habit_tracking_app/security/advisories/new)
- Email: andres9888@gmail.com

Please include:

- A description of the vulnerability and its impact
- Steps to reproduce (proof-of-concept if possible)
- Affected version, branch, or commit

## Response

- Acknowledgement within **72 hours**
- An assessment and remediation timeline after triage
- Coordinated disclosure once a fix is released

Thank you for helping keep this project and its users safe.
