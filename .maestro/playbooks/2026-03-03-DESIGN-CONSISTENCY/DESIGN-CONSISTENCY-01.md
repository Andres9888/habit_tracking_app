# P0: Dark Mode Gaps — BinaryHeatmap & MonthlyCalendarGrid

These components have fully hardcoded light-mode color palettes that will render unreadable in dark mode. Convert them to accept theme colors via props or use `useThemeColors()`.

## Context

- Theme system: `useThemeColors()` from `@/theme/ThemeContext` returns `{ colors, isDark }` where `colors` implements `SemanticColors` interface
- Light palette: `lightColors` from `@/theme/darkColors` — warm stone tones (`#F5F1ED` bg, `#EDEAE5` card)
- Dark palette: `darkColors` from `@/theme/darkColors` — cool grays (`#111827` bg, `#1F2937` card)
- Static colors: `colors` from `@/theme/colors` — palette scales (primary, gray, streak, etc.)
- Shadows: `shadows` from `@/theme/spacing` — 5 levels (subtle, card, floatingActionButton, modal, alert) using `#2D2A26`
- Border radius: `borderRadius` from `@/theme/spacing` — xs:4, small:8, medium:12, large:16, xl:24, full:9999
