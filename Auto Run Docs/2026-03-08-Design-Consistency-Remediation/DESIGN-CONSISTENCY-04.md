# Phase 04: Hardcoded Color Remediation

**Goal:** Replace hardcoded hex color values in component files with references to the `colors.*` token system from `@/theme/colors` or `@/theme`.

**Context:** ~200 hardcoded hex colors exist across 30+ component files. This phase targets the highest-impact files first. Each task groups files by feature area. Files should import `{ colors }` from `@/theme/colors` or `@/theme` (match existing import pattern in each file).

**Important:** Some colors may be intentionally unique (e.g., category-specific brand colors that aren't part of the design system). For those, add a `// Intentional: category brand color` comment rather than forcing a token mapping.
